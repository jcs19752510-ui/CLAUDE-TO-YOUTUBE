> 메인 영상(`01_클로드코드_사용법_메인대본.md`, 15분 버전)에서 약속한 자료입니다. 인쇄하거나 캡처해 두고 쓰세요.
> ⚠ 명령어·단축키·메뉴는 업데이트로 바뀔 수 있습니다. 배포 전에 `/help`와 공식 문서로 한 번 확인하고 〈확인〉 표시를 지우세요.

## 1. 시작 3줄

```
1) 빈 폴더를 만든다
2) 터미널에서 그 폴더로 이동한다
3) claude 를 입력한다   →  로그인  →  폴더 신뢰  →  시작!
```

## 2. 필수 명령어 한 장 (슬래시 명령)

| 명령 | 하는 일 | 언제 쓰나 |
|---|---|---|
| `/help` | 도움말 | 모르면 제일 먼저 |
| `/init` | CLAUDE.md 초안 자동 생성 | 새 프로젝트 시작할 때 |
| `/model` | 모델 변경 | 비용 아끼고 싶을 때 |
| `/compact` | 대화 요약 압축 | 대화가 길어질 때 |
| `/clear` | 대화 전체 지우기 | 완전히 새로 시작할 때 (기억 사라짐!) |
| `/context` | 기억 공간 사용량 확인 | 얼마나 쓴지 궁금할 때 |
| `/doctor` | 상태 점검 | 이상하게 동작할 때 |
| `/exit` | 종료 | 나갈 때 |

〈확인: 위 명령이 현재 버전에서 동일한지〉

## 3. 키보드 · 입력 팁

| 입력 | 효과 |
|---|---|
| `Shift + Tab` | 모드 전환(기본 / 자동 승인 / 계획) 〈확인〉 |
| `Esc` | 진행 중인 작업 멈춤 |
| `Esc` 두 번 | 이전 시점으로 되돌리기 메뉴 〈확인〉 |
| `@파일이름` | 특정 파일만 지정 |
| `!명령` | 클로드 해석 없이 바로 실행 (빠름) |
| 이미지 끌어놓기 | 캡처를 보여 주며 질문 |
| `claude --resume` | 지난 대화 골라서 이어하기 〈확인〉 |

## 4. 어떤 도구를 쓸까? (30초 선택표)

| 원하는 결과물 | 도구 |
|---|---|
| 답변·생각 정리 | 챗 |
| 정리된 파일·문서 | 코워크 |
| 계속 쓸 웹사이트·앱·도구 | **클로드 코드** |

## 5. 초보 실수 3가지

| # | 실수 | 해결 |
|---|---|---|
| 1 | 한 번에 너무 큰 요청 | 작게 쪼개기, 큰 건 **계획 모드부터** |
| 2 | 처음부터 "모두 허용" | 처음엔 **한 번씩 승인**하며 확인 |
| 3 | 꼬이면 바로 `/clear` | 먼저 `/compact` |

## 6. 첫 프롬프트 예시 (복붙용)

```
부업 수익 계산기 웹페이지 만들어 줘.
수입과 비용을 여러 개 입력하면 순이익이 바로 계산되게 해 줘.
디자인은 깔끔하고 모바일에서도 보이게 해 줘.
```

```
(복잡한 기능은 계획 모드에서)
월별 기록 저장 기능을 추가하고 싶어.
만들기 전에 나한테 먼저 질문해서 요구사항을 정리해 줘.
```

```
(작업을 끝낼 때)
오늘 한 작업을 정리해서 HANDOFF.md 파일로 저장해 줘.
다음에 이어서 할 수 있도록 현재 상태와 남은 일을 적어 줘.
```

## 7. CLAUDE.md 시작 템플릿

> 프로젝트 폴더 맨 위에 `CLAUDE.md`로 저장하세요. 먼저 `/init`으로 초안을 만든 뒤, 아래 줄을 필요한 만큼만 추가하는 걸 권장합니다.

```markdown
# 〈프로젝트 이름〉

## 이 프로젝트는
〈무엇을 만드는지 한 줄. 예: 부업 수익을 계산하는 한 페이지 웹사이트〉

## 작업 규칙
- 모든 답변과 설명은 한국어로 한다.
- 어려운 용어는 쉬운 말로 한 줄 풀이를 덧붙인다.
- 파일을 바꾸기 전에 무엇을 바꿀지 먼저 말한다.
- 한 번에 한 가지씩 작게 작업한다.
- 작업이 끝나면 무엇을 바꿨는지 세 줄 이내로 요약한다.
- 확실하지 않은 것은 추측하지 말고 확인하거나 질문한다.

## 하지 말 것
- 〈내가 싫어하는 행동을 계속 추가. 예: 허락 없이 새 라이브러리를 설치하지 않는다〉
```

**규칙 하나 추가하는 법**
> 클로드가 마음에 안 드는 행동을 하면 → "이 행동을 막는 규칙을 CLAUDE.md에 한 줄로 추가해 줘"라고 시키세요.
