# AI 인물 출연 가이드 (확인용 샘플 목적)

> 목적: 샘플 영상에서 인물이 나오는 위치·크기·구간을 확인. 최종 배포는 직접 촬영본을 사용.
> 서비스 화면·메뉴는 자주 바뀝니다. 아래 단계는 일반적인 흐름이며, 화면에 보이는 이름을 따르세요. 요금·한도는 각 공식 페이지에서 확인.

## 출연 구간 (권장)
| 구간 | 길이 | 대사 |
|---|---|---|
| 오프닝 | 15초 | ① 첫 두 문단 (V01_p00~p01) |
| 10분 체크포인트 | 20초 | ④ 첫 문단 (V04_p00) |
| 20분 전환 | 20초 | ⑥ 첫 문단 (V06_p00) |
| 엔딩 | 20초 | ⑧ 마지막 두 문단 |
나머지는 화면 녹화 + 카드. 얼굴을 27분 내내 띄우지 않습니다.

## 방법 1. 직접 촬영 (최종 배포와 동일, 가장 정확)
1. 스마트폰 가로 촬영, 창가 자연광 정면, 조용한 방.
2. 한 번에 한 구간씩 15~20초 촬영, 앞뒤 3초 정지.
3. 편집에서 오른쪽 아래 작은 창(PIP)으로 얹기.

## 방법 2. 무료 웹 서비스로 사진 같은 인물 만들기 (확인용)
공통 준비: ① 말할 음성 mp3(오늘은 `음성/_이전버전/V01_p00.mp3`, 내일부터는 `음성/V01_p00.mp3`) ② 얼굴 사진 = **AI가 만든 가상 인물 또는 본인 사진만** (타인 사진 금지).
순서(서비스 공통): 가입 → 새 영상/아바타 만들기 → 사진 또는 스톡 아바타 선택 → **음성 파일 업로드(오디오 모드)** 선택 → 한국어 설정 → 생성 → 다운로드.
추천 시험 순서(10초만 만들어 입 모양·한국어·워터마크 확인):
1. Free.ai (자체 안내: 워터마크·분 제한 없음, 스톡 아바타 8종. 독립 확인은 안 됨)
2. Dreamina(CapCut) (무료 생성 안내, 조건 미확인)
3. HeyGen 무료(월 1~3편, 워터마크 가능)
4. Vidnoz 무료(하루 1~3분, 워터마크)
5. AI STUDIOS(월 최대 3편), Synthesia(월 1편), Hedra 무료, D-ID 14일 체험
※ 텍스트로 만드는 모드는 서비스 음성이 나옵니다. 우리 Gemini 음성을 쓰려면 **오디오 업로드 모드**가 있는 서비스를 고르세요.

## 방법 3. 오픈소스 직접 실행 (GPU 있는 PC)
InfiniteTalk(긴 영상), MuseTalk(입 모양), SadTalker(사진 한 장). 각 저장소 설치 안내를 따르고 모델 라이선스를 확인. 이 클라우드 환경은 GPU·모델 다운로드가 안 돼서 실행하지 못했습니다.

## 방법 4. 2D 캐릭터 (즉시, 이미 제작)
`샘플/AI인물_합성샘플.mp4` / `샘플/make_avatar_sample.py 음성.mp3 …` 로 다른 음성에도 만들 수 있음.

## 편집에서 얹는 법 (CapCut 등 공통)
1. 아바타 영상을 가장 위 트랙에 올린다.
2. 크기 25~30%, 오른쪽 아래 여백 약 2%. 카드 글자를 가리지 않는지 확인.
3. 배경이 단색이면 "배경 제거/크로마키" 사용.
4. 음성은 아바타 영상의 소리를 쓰고, 카드(G##)는 아래 트랙.

## 확인 체크리스트
- 입 모양이 한국어 음절과 맞는가 / 눈·고개가 부자연스럽지 않은가
- 워터마크 위치가 화면 요소를 가리지 않는가
- 오른쪽 아래 위치가 카드·자막과 겹치지 않는가
- 유튜브 업로드 시 "변경·합성 콘텐츠" 질문 안내를 확인 (확인 필요)
