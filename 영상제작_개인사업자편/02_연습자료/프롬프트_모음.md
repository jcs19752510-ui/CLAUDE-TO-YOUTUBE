# 복사해서 붙일 문장 모음 (영상 순서대로)

> 연습용 가짜 가게 '하루쿠키' 기준입니다. 내 가게에 맞게 상품 이름·규칙만 바꿔 쓰세요.
> 실제 고객 이름·전화번호·주소·비밀번호는 절대 넣지 마세요.

## ③ 첫 실행
1. 가게 소개
```
상품정보 파일을 읽고, 하루쿠키를 처음 보는 손님에게 소개하는 글을 다섯 줄로 써서 가게소개 파일로 저장해 줘.
```
2. 업무 지침서
```
이 폴더에서 일할 때 지킬 규칙을 지침서 파일로 만들어 줘. 규칙: 존댓말을 쓴다. 가격과 설명은 상품정보 파일에 있는 내용만 쓴다. 효과나 건강에 좋다는 식의 과장은 쓰지 않는다. 모르는 건 지어내지 말고 나에게 물어본다.
```

## ④ 홍보 글 일주일 치
```
상품정보 파일을 보고 인스타그램과 블로그에 올릴 일주일 치 홍보 글을 만들어 줘. 하루에 하나씩 일곱 개를 홍보글 폴더에 1일차부터 7일차까지 파일로 저장해 줘. 각 글은 세 줄 소개, 사진은 이렇게 찍자는 제안 한 줄, 해시태그 다섯 개로 구성해 줘. 가격은 상품정보 파일의 숫자만 쓰고, 지침서 규칙을 지켜 줘.
```
수정: `3일차 글을 더 따뜻한 말투로 다시 써 줘.`
주력 상품: `이번 주에는 선물세트를 가장 많이 알리고 싶어. 일곱 개 중 네 개는 선물세트 중심으로 다시 써 줘.`

## ⑤ 문의 답변 + 주문 정리
```
문의_목록 파일의 문의 여덟 건에 대한 답변 초안을 답변초안 파일로 만들어 줘. 답변은 상품정보 파일에 있는 사실만 써. 상품정보에 없는 내용은 '확인 후 안내드리겠습니다'라고 써 줘. 고객마다 번호와 고객 이름을 제목으로 달아 줘.
```
```
주문_내역 파일에서 상태가 취소인 주문은 빼고, 총 매출과 상품별 판매 수량과 매출을 표로 만들어서 이번달_주문요약 파일로 저장해 줘. 계산 과정도 같이 적어 줘.
```
**정답**: 12건 · 총매출 239,000원 · 버터쿠키 12개 78,000원 · 말차쿠키 5개 35,000원 · 선물세트 7개 126,000원

## ⑥ 홈페이지 (권한 모드: Plan)
```
하루쿠키 소개 페이지를 index.html 한 장으로 만들고 싶어. 상품 세 개와 가격, 주문 방법, 알레르기 안내를 넣어 줘. 글씨는 크고 읽기 쉽게, 휴대폰 화면에서도 잘 보이게 해 줘. 먼저 계획만 보여 줘.
```
수정: `주문하기 버튼을 맨 위로 올리고, 글씨를 더 크게 해 줘.`
되돌리기: `방금 바꾼 걸 되돌려 줘.` (중요한 파일은 미리 복사본)
