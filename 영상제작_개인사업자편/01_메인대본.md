> 유지 장치: 결과물 3개 먼저(콜드 오픈) → 약속 → 대상 안심 → 자료 안내 → 다음 예고.

**[편집]** 말이 시작되면 결과물 화면이 0.7초씩 빠르게 지나간다: ① 일곱 개 파일이 생기는 폴더 ② 답변 초안 문서 ③ 완성된 쿠키 가게 페이지.
**[자막]** `말 몇 줄 → 홍보 글 7개 · 답변 8개 · 홈페이지 1장`

🎙 말 몇 줄로, 일주일 치 홍보 글 일곱 개와 고객 문의 답변 여덟 개, 그리고 가게 소개 홈페이지 한 장이 만들어졌습니다. 코딩은 한 줄도 안 했어요.

🎙 이걸 해 준 도구가 클로드 코드입니다. 사장님 컴퓨터에서도, 오늘 영상이 끝나기 전에 똑같이 돌아가게 만들어 드릴게요.

🎙 스무 살에 첫 가게를 여는 분도, 퇴직하고 새로 시작하는 오십 대 사장님도 괜찮습니다. 프로그램 설치할 줄만 아시면 돼요. 어려운 말은 쓰지 않고, 클릭할 곳을 하나하나 짚어 드립니다.

## ② 왜 클로드 코드인가 + 설치 (1:30 ~ 5:30)
> 유지 장치: 통증("혼자 다 한다") → 보여주기(세 탭 비교, 설치 화면) → 작은 성공(코드 탭이 열린다) → 다음 예고(폴더 하나 만들기).
> 음성 V02 · 목표 약 1,050자

**[화면]** 책상 위 해야 할 일 카드가 쌓이는 모션그래픽: `홍보 글` `문의 답장` `주문 정리` `홈페이지`.
**[자막]** `혼자 다 하느라 정작 가게는 못 돌본다`

🎙 가게를 준비하면 할 일이 끝이 없죠. 홍보 글 쓰고, 문의에 답장하고, 주문 정리하고, 홈페이지까지 만들어야 합니다. 이걸 혼자 하다 보면 정작 상품을 만들 시간이 모자라요.

🎙 클로드 코드는 이런 반복 일을 말로 시키면, 내 컴퓨터 폴더 안에서 파일을 만들고 고쳐 주는 도구입니다. 검은 화면에 명령어를 치는 그 방식이 아니에요. 클로드 데스크탑 앱 안에 코드 탭이 있고, 거기서 폴더를 고르고 말로 시키면 됩니다.

**[화면]** 클로드 데스크탑 앱 상단의 탭들을 하나씩 짚는다. 〈본인 화면에 보이는 이름 그대로 촬영〉
**[자막]** `챗 = 물어보기 · 코워크 = 목표 맡기기 · 코드 = 내 폴더 파일 만들고 고치기`

🎙 앱에는 비슷해 보이는 기능이 세 개 있습니다. 챗은 물어보고 답을 듣는 곳이에요. 내 컴퓨터 파일에는 접근하지 않습니다. 코워크는 목표를 맡기면 파일과 도구를 써서 알아서 일하고 결과를 가져옵니다. 코드는 내가 고른 폴더 안에서 파일을 직접 만들고 고치는 곳이에요.

🎙 오늘은 이 중에 코드 탭 하나만 씁니다. 홍보 글도, 답변 초안도, 홈페이지도 전부 파일이라서 코드 탭에서 한 번에 되거든요. 참고로 계정에 따라 챗과 코워크가 한 화면으로 합쳐져 있을 수 있어요. 화면이 조금 달라도 코드 탭만 찾으시면 됩니다.

**[화면]** 준비물 체크리스트 카드.
**[자막]** `준비물: 맥 또는 윈도우 컴퓨터 · 이메일 · 유료 요금제`
🎙 준비물은 세 가지예요. 맥이나 윈도우 컴퓨터, 로그인할 이메일, 그리고 유료 요금제. 휴대폰만으로는 오늘 영상처럼 폴더 안 파일을 만드는 작업이 어렵습니다. 컴퓨터를 켜 놓고 따라 해 주세요.

**[화면]** 요금제 안내 자막.
**[자막]** `챗: 무료 포함 모든 요금제 · 코드·코워크: 프로 이상 유료`

🎙 여기서 먼저 알아 두실 게 있어요. 챗은 무료 요금제에서도 쓸 수 있지만, 코드와 코워크는 프로 이상의 유료 요금제가 필요합니다. 요금은 바뀔 수 있으니 금액은 공식 요금 페이지에서 직접 확인하세요. 사업에 쓸 도구니까, 내가 쓸 만큼 도움이 되는지 오늘 영상으로 먼저 판단해 보셔도 좋습니다.

**[화면]** 공식 다운로드 페이지(주소 줄 확대). 가짜 비슷한 이름의 사이트 경고 카드.
🎙 설치는 공식 다운로드 페이지에서만 하세요. 비슷한 이름의 다른 사이트에서 받으면 안 됩니다. 사업을 하면 이런 가짜 사이트에 노출될 일이 더 많아요. 주소를 꼭 확인하세요.

**[화면]** 맥은 다운로드 포 맥오에스 버튼, 윈도우는 마이크로소프트 스토어 또는 직접 내려받기. 설치 후 앱 실행 → 로그인 → 코드 탭 클릭.
🎙 맥은 맥오에스용 다운로드 버튼을 누르고, 윈도우는 마이크로소프트 스토어나 직접 내려받기로 설치합니다. 설치가 끝나면 앱을 열고 클로드 계정으로 로그인하세요. 그다음 코드 탭을 누릅니다.

**[화면]** 막힐 수 있는 세 가지를 카드로.
**[자막]** `① 업그레이드 안내 = 유료 요금제 필요 ② 온라인 로그인 안내 = 로그인 후 앱 재시작 ③ 윈도우 깃 안내 = 그때만 깃 설치`
🎙 막히는 곳이 세 군데 있어요. 코드 탭에서 업그레이드 안내가 뜨면 유료 요금제가 필요하다는 뜻입니다. 온라인으로 로그인하라는 안내가 뜨면, 안내대로 로그인을 마친 뒤 앱을 다시 시작하세요. 윈도우에서 깃이 필요하다고 나올 때만 깃을 설치하면 됩니다. 이 외에 따로 설치할 건 없어요.

**[화면]** 코드 탭이 열려 입력창이 보이는 화면에 체크 표시.
**[자막]** `코드 탭이 열렸다면 준비 끝`
🎙 코드 탭이 열렸다면 준비는 끝났습니다. 이제 사장님 가게 일을 시킬 폴더를 하나 만들 차례예요.
