## 0. 먼저 알아둘 점 (정직하게)

- 레퍼런스 3편의 조회수는 **11만 ~ 28.5만**입니다. 50만을 넘은 영상은 없습니다. 이 구성안은 "50만 보장"이 아니라 "이 3편이 증명한 공식 + 이 3편에 없는 차별점"을 조합한 설계입니다. 조회수는 약속할 수 없습니다.
- 자막은 유튜브 **자동 생성 자막**이라 오탈자가 많고 같은 문장이 반복됩니다. 인용은 의미 위주로 했습니다.
- 3편의 자막 원문은 저작물이므로 **저장소에 올리지 않았습니다.** 구조·공식만 참고하고, 문장·화면 구성을 복제하지 마세요.
- 클로드와 나눈 실제 대화는 저장소에 없어서, 프로젝트 소재는 커밋·결정 기록에서 복원한 것입니다.

### 숫자가 말해 주는 것 (해석이므로 단정은 아님)

2. **① 영상은 좋아요율이 가장 높습니다(1.97%).** 따라 하는 실습형은 만족도가 높습니다. 길이(47분)를 감수하고도 저장·재시청 수요가 있습니다.

4. **8월(②③)에는 "올인원/총정리 + 코워크·스킬·MCP"가 유행**하고, 2월(①)에는 "Claude Code 입문"이었습니다. 시청자의 관심이 *도구 하나 → 생태계 전체와 선택 기준*으로 이동했습니다.

## 2. 3편의 공통 성공 공식 (7가지)

1. **제목 = 연도(2026) + 규모 숫자(23가지/20분) + 무료/올인원/총정리 + 대상(왕초보)**
2. **첫 15초에 시청자의 통증 한 문장** (②) 또는 **완성 결과물** (③). 설명으로 시작하지 않음.
3. **"언제 뭘 쓰나" 판단 기준 표** (②③이 영상 후반 핵심으로 배치). 기능 나열이 아니라 *선택 기준*이 가치.
4. **무료 자료로 구독·카톡방 유입** (3편 모두). 고정 댓글/설명란/오픈채팅.
5. **챕터 타임스탬프 8~30개.** 점프 시청이 가능해 완주율·저장률에 유리.
6. **본인 신뢰 한 줄** (박사, 200건, 대기업 강의).
7. **마무리에서 다음 영상 연결** (①은 MCP·스킬·에이전트 예고).

### 영상 본문 핵심 장면 (촬영 소재)

**③ 규칙 파일 전/후** — 실제 규칙(`CLAUDE.MD` 상시 규칙)
- 전: 클로드가 "사용자 PC에서 실행해 보세요"라고 떠넘김
- 규칙 한 줄: *"내부 테스트는 에이전트가 직접 한다. 사용자에게 시키지 않는다."*
- 후: PowerShell을 직접 내려받아 스크립트 22건을 스스로 실행·검증(DEC-094)
- 왕초보 메시지: **"클로드가 자꾸 나한테 시키면, 규칙 파일에 한 줄 쓰세요."**

**⑤ 사고 공개 (DEC-092) 편집 포인트**
1. 증상: 화면이 10/1에서 정지 (스케줄러는 정상)
2. 의심: "서버 문제?" → 아님
3. 원인: 공공데이터는 +1영업일 뒤 공개, 10/5 대체공휴일 → 10/2 데이터는 10/6에 공개. 그 사이 실패 3회 → 시스템이 영구히 건너뜀.
4. 해결: 공개 전 실패를 시도 횟수에서 제외 + **옛 코드에서 실패하고 새 코드에서 통과하는 재현 시험**
5. 교훈: "AI에게 *고치라*고만 하지 말고, *재현 시험부터 쓰게* 하세요."

**⑥ 사람이 결정한 4가지**
1. 상용 시세 벤더를 쓰지 않고 본인 PC 전용 + 증권사 Open API (DEC-097)
2. "투자 권유 표현 금지" 문구 검사 도입 (`lint:copy`)
3. 배포는 사람 승인 필수(하네스 12단계)
4. 보안 이야기는 나중으로 미룬다는 방침 → **이건 따라 하지 말라고 반면교사로** 말하기 (HANDOFF에 "보안 이야기는 하지 않는다"가 상시 규칙으로 적혀 있음. 영상에서는 "이 프로젝트는 개인용이라 미뤘지만, 공개 서비스라면 먼저 해야 한다"로 정직하게 설명)

## 6. 수익·정책 주의 (AI 왕초보 + 수익창출 타겟)

- ②③은 **고정 댓글·오픈채팅·유료 강의·기업 교육**으로 수익화합니다. 같은 구조를 쓰되, 우리 차별점은 "실제 서비스 기록 + 템플릿 배포"입니다.
- 서비스 자체는 **개인용 분석 도구**입니다. "이걸로 돈 번다"로 포장하지 마세요. 수익은 *콘텐츠·템플릿·교육·외주*에서 나옵니다.
- **금융 콘텐츠**: 특정 종목 추천, 수익 보장 표현 금지. 화면에 종목이 보이면 "예시 화면, 투자 권유 아님" 고지. 실제 계좌·잔고 화면 금지.
- **비밀값**: `.env`, 증권사 앱키, Render/Neon 환경변수 화면은 촬영 제외. 저장소가 공개 상태이므로 커밋 이력에 비밀값이 없는지 점검 후 촬영.
- **저작권/윤리**: 레퍼런스 3편의 문장·구성·화면을 복제하지 말고 *공식*만 응용. 다른 영상을 인용하면 출처 표기.
