# 영상 제작 가이드 — 유튜브 초보용 (처음부터 업로드까지)

> 이 가이드는 **"클로드 코드 사용법 15분"** 영상을 처음 만드는 사람을 위한 순서표입니다. 위에서부터 **차례로** 하세요.
> 도구·메뉴·요금은 자주 바뀝니다. 화면이 조금 다르면 비슷한 이름의 메뉴를 찾으세요. 확인이 필요한 부분은 ⚠로 표시했습니다.

## 0. 전체 그림 (한눈에)

```
[1] 준비물 갖추기  →  [2] 사실 확인·연습  →  [3] 화면 녹화  →  [4] 얼굴·목소리 촬영
        →  [5] 편집(자르기·자막·그래픽)  →  [6] 내보내기  →  [7] 유튜브 업로드  →  [8] 업로드 후 점검
```

| 단계 | 내가 할 일 | 걸리는 시간(처음, 어림값) |
|---|---|---|
| 1 | 장비·프로그램 준비 | 1~2시간 |
| 2 | 사실 확인 + 연습 | 2~3시간 |
| 3 | 화면 녹화 (B1~B11) | 1~2시간 |
| 4 | 얼굴·목소리 촬영 (A1~A10) | 1.5~3시간 |
| 5 | 편집 | 4~8시간 |
| 6 | 내보내기 | 30분 |
| 7 | 업로드 설정 | 1시간 |
| 8 | 업로드 후 점검 | 24시간·72시간 후 각 15분 |

> 처음엔 오래 걸리는 게 정상입니다. 두 번째 영상부터 절반으로 줄어듭니다.

## 1단계. 준비물 갖추기

### 1-1. 장비

| 장비 | 꼭 필요? | 추천 | 비고 |
|---|---|---|---|
| 컴퓨터 | 필수 | 평소 쓰는 PC | 화면 녹화 + 편집용 |
| 마이크 | **필수** | 유선 이어폰 마이크 / 핀 마이크 / USB 마이크 | **소리가 영상 품질의 절반입니다** |
| 카메라 | 필수 | 스마트폰(1080p 이상) | 가로 촬영 |
| 삼각대·거치대 | 권장 | 저렴한 것도 OK | 손으로 들면 흔들림 |
| 조명 | 권장 | 창문 + 스탠드 | 얼굴이 밝게 |
| 헤드폰 | 선택 | 아무 이어폰 | 편집 때 소리 확인 |

> **전문가 기준 한 줄**: 시청자는 화면이 조금 거칠어도 보지만, **소리가 나쁘면 바로 나갑니다.** 예산이 한정이면 마이크부터 사세요.

### 1-2. 프로그램 (모두 무료 또는 무료 버전 있음) ⚠ 요금·기능은 확인

| 용도 | 프로그램 | 이유 |
|---|---|---|
| 화면 녹화 | **OBS Studio** | 무료, 가장 널리 쓰임 |
| 편집(쉬움) | **Vrew (브루)** | 한국어 자동 자막, 말 자르기가 쉬움 |
| 편집(자유도) | **CapCut(캡컷)** 또는 다빈치 리졸브 | 그래픽·효과 얹기 |
| 이미지 확인 | 기본 사진 앱 | 썸네일 확인 |

**처음이라면 추천 조합**: OBS(화면 녹화) + Vrew(말 자르기·자막) + CapCut(그래픽 얹기·내보내기).
Vrew 하나로 시작해도 되지만, 도식 영상을 얹을 때는 CapCut이 편합니다.

### 1-3. 파일 정리 (이거 안 하면 편집 때 길을 잃습니다)

바탕화면에 **`클로드코드영상`** 폴더를 만들고 아래 하위 폴더를 만드세요.

```
클로드코드영상/
├─ 01_화면녹화/      (B1~B11)
├─ 02_얼굴촬영/      (A1~A10)
├─ 03_그래픽/        (그래픽/영상_mp4 폴더의 10개 파일을 복사)
├─ 04_자막/          (강조자막_초안.srt)
├─ 05_음악/          (배경음)
├─ 06_편집프로젝트/
└─ 07_완성본/
```

**파일 이름 규칙**: `B6_첫프로젝트_1.mp4`, `A3_선택표_2.mp4` 처럼 **번호_내용_순번**. 나중에 찾기 쉽습니다.

## 3단계. 화면 녹화 (OBS)

### 3-1. OBS 처음 설정 (한 번만) ⚠ 메뉴 이름은 버전마다 다를 수 있음
1. OBS를 설치하고 실행합니다.
2. 아래쪽 **소스(Sources)** 칸에서 **`+` → "화면 캡처"(Display Capture)** 를 추가합니다.
3. 오른쪽 아래 **설정(Settings)** → **출력(Output)**: 녹화 형식 `mp4` 또는 `mkv`(안전).
   - ⚠ `mkv`로 녹화하면 갑자기 꺼져도 파일이 보존됩니다. 끝난 뒤 `파일 → 녹화 리먹스(Remux)`로 mp4 변환.
4. **설정 → 영상(Video)**: 기본 해상도·출력 해상도 모두 **1920×1080**, FPS **30**.
5. **설정 → 오디오**: 마이크가 "마이크/보조 오디오"에 잡히는지 확인(필요 시 화면 녹화에서는 마이크 없이 영상만 녹화해도 됩니다. 목소리는 얼굴 촬영 때 따로 녹음하는 방식이 편집이 쉽습니다).

### 3-2. 녹화 전 정리
- 터미널·에디터 글자 크기 **1.5배**
- 바탕화면 아이콘 정리, 알림·메신저 끄기, 브라우저 즐겨찾기 가리기
- `.env`, API 키, 계정 정보, 개인 파일이 화면에 안 나오게
- 시연용 데이터는 **가짜 숫자**만

### 3-3. 녹화 순서
`06_샷리스트_편집타임라인.md`의 **B1 → B11** 순서로. 클립마다:
1. 녹화 시작 → **3초 가만히** → 시연 → **3초 가만히** → 녹화 중지
2. 틀렸으면 **그 클립만** 다시 (이어서 계속 틀리지 말고 멈추고 다시)
3. 파일 이름을 바로 `B6_첫프로젝트_1.mp4`처럼 바꿔 `01_화면녹화`에 저장

## 4단계. 얼굴·목소리 촬영

### 4-1. 자리 세팅 (한 번만)
- 스마트폰을 **가로**로, **눈높이**, 얼굴이 화면 **가운데 위쪽**
- **창문을 마주 보고** 앉기 (뒤에서 빛이 오면 얼굴이 어두워집니다)
- 배경은 **단순하게** (정리된 벽·책장). 뒤에 개인 정보(주소·서류)가 없게
- 조용한 방: 에어컨·냉장고 소리 끄기, 문 닫기

### 4-2. 소리 점검 (30초만 투자)
- 10초 말해서 녹음 → 이어폰으로 들어 보기
- 웅웅거림(울림)이 크면 **이불·커튼 있는 곳**이나 **작은 방**으로 옮기세요. 헤드폰으로 들었을 때 깨끗해야 합니다.

### 4-3. 말하는 방법 (초보 필수)
1. `07_읽기용_대본.md`를 모니터에 띄우고 **카메라 렌즈 근처**에 두세요.
2. **한 문단씩 읽고 멈추기**. 틀리면 그 문단 처음부터 다시.
3. **처음 5초 전에 박수 한 번** → 소리 파형에서 시작점이 보입니다.
4. 말 끝에 **1초 쉬기** → 자르기 쉽습니다.
5. 평소보다 **약간 밝고 또렷하게** 말하세요. 너무 빠르면 왕초보는 못 따라옵니다.

### 4-4. 촬영 순서
`06_샷리스트_편집타임라인.md`의 **A1 → A10** 순서로 찍습니다.
- 같은 자리·같은 옷·같은 조명으로 **한꺼번에** (날 나눠 찍지 않기)
- 각 클립 끝에 **3초 가만히**

## 5단계. 편집 (순서대로)

### 5-1. 큰 흐름
```
(1) 모든 파일 모으기 → (2) 말 자르기 → (3) 순서대로 이어 붙이기 → (4) 화면 녹화 얹기
→ (5) 도식 영상 넣기 → (6) 강조 자막 넣기 → (7) 소리 다듬기 → (8) 배경음 → (9) 확인 → (10) 내보내기
```

### 5-2. Vrew로 "말 자르기 + 자동 자막" (가장 쉬운 방법) ⚠ 메뉴·요금은 확인
1. Vrew를 실행 → **새로 만들기** → **PC에서 비디오·오디오 불러오기** → `02_얼굴촬영`의 영상을 선택합니다.
2. 언어를 **한국어**로 두고 분석을 시작합니다. 말한 내용이 **글자로 나옵니다**(자동 자막).
3. 글자 중 **틀린 부분을 고치고**, 필요 없는 부분(NG, "음…", 긴 공백)을 **글자 단위로 삭제**하면 영상에서도 잘립니다. 이게 Vrew의 핵심입니다.
4. 클립마다 반복(A1~A10). 또는 이어 붙여서 한 프로젝트로 작업합니다.
5. 완성되면 **내보내기**로 영상 파일(mp4)과 **자막 파일(SRT)** 을 저장합니다.

> Vrew가 만든 SRT는 **대사 자막**입니다. 제가 만든 `강조자막_초안.srt`는 **큰 글씨 강조 자막**(예: "결과물이 뭐냐?") 용도로, 둘은 다릅니다.

### 5-3. CapCut으로 "이어 붙이기 + 그래픽 얹기"
1. CapCut을 실행 → **새 프로젝트**. 비율 **16:9**.
2. **미디어 가져오기**: `01_화면녹화`, `02_얼굴촬영`(또는 Vrew에서 내보낸 영상), `03_그래픽`의 mp4를 모두 불러옵니다.
3. 타임라인에 **얼굴 영상**을 먼저 올립니다(말이 기준 줄기).
4. 화면 녹화(B)를 `06_샷리스트_편집타임라인.md` 표대로 **그 위 트랙에 올려** 해당 구간을 덮습니다. 소리는 **얼굴 영상의 목소리**를 유지합니다.
5. 도식 영상(🎞)도 같은 표대로 올립니다. 시작 시간만 맞추면 됩니다.
6. 긴 대기(설치 중, 생성 중)는 **클립을 선택 → 속도 2~4배**로 줄입니다.
7. 화면 녹화에서 중요한 부분은 **확대(줌인)** 해서 모바일에서도 보이게 합니다.

### 5-4. 강조 자막 넣기
1. CapCut: **텍스트 → 자막 → 자막 파일 가져오기(SRT)** 로 `강조자막_초안.srt`를 가져옵니다.
2. ⚠ 시간은 **초안(대략)** 입니다. 실제 영상에서 **말이 나오는 시점에 맞춰** 하나씩 끌어서 이동하세요.
3. 이미 도식 영상이 보여 주는 문구(예: 설치 3단계)는 자막이 **겹치므로 지우세요.**
4. 모양: **흰 글씨 + 검은 외곽선**, 크기 크게, 화면 **아래 1/3** 위치, 한 줄 **15자 내외**.

### 5-5. 소리 다듬기 (효과 큼)
- **노이즈 제거**(편집 프로그램의 "음성 보정/노이즈 제거") 켜기
- 말소리가 일정한 크기가 되도록 **음량 평준화**
- 배경음은 **말소리보다 훨씬 작게** (말소리가 들리는 구간에서는 배경음을 −20dB 정도로 낮춤)
- 유튜브는 소리를 자동으로 맞춰 줍니다. ⚠ 흔히 **−14 LUFS** 부근을 기준으로 언급하지만, 정확한 값은 확인하세요. 초보는 "말소리가 깨끗이 들리는지"만 보면 됩니다.

### 5-6. 배경음(BGM) 저작권 ⚠ 중요
- 가요·팝·영화 음악은 **쓰지 마세요**(저작권 문제).
- **유튜브 스튜디오의 오디오 보관함**(무료 음악) 또는 **상업 이용 가능한 무료 음원**만 쓰세요. 이용 조건을 꼭 읽으세요.
- 배경음 없이도 됩니다. 말소리가 깨끗한 게 훨씬 중요합니다.

### 5-7. 전문가 기준 편집 감각 5가지
1. **처음 5초**에 결과물(계산기)이 나오게.
2. **30~40초마다 화면이 바뀌게** (얼굴 → 화면 → 도식 → 얼굴). 한 화면이 길어지면 이탈.
3. **말 사이 공백을 과감히 자르기** (무호흡 편집). 하지만 너무 빡빡하면 숨차 보입니다. 0.2~0.4초 여유.
4. 중요한 건 **크게, 한 번에 하나만** 보여 주기.
5. **줄이는 게 늘리는 것보다 낫습니다.** 확신 없는 부분은 뺍니다.

### 5-8. 내보내기 (CapCut/편집 프로그램) ⚠ 메뉴 이름은 다를 수 있음
| 항목 | 설정 |

## 6단계. 유튜브 업로드 (YouTube Studio) ⚠ 메뉴 이름·순서는 바뀔 수 있음

### 6-1. 올리기 전 준비물 체크
- [ ] 완성 영상 mp4
- [ ] 썸네일: `최종_확정_챗COWORK_15분.webp` → ⚠ 업로드용은 **JPG/PNG, 1280×720, 2MB 이하** 권장이니 필요하면 변환
- [ ] 제목, 설명란, 고정 댓글(`01_클로드코드_사용법_메인대본.md` 부록 A·B)
- [ ] 치트시트 다운로드 링크(구글 드라이브 공유 링크 등) ⚠ 링크가 열리는지 직접 확인
- [ ] 〈 〉 빈칸 모두 채움

### 6-2. 업로드 순서
1. youtube.com 로그인 → 오른쪽 위 **만들기(+) → 동영상 업로드**
2. 영상 파일 끌어놓기
3. **세부정보** 화면
   - **제목**: `2026 클로드 코드 사용법｜챗·코워크·코드 15분 총정리 (왕초보 · 무료 치트시트)` ⚠ 실제 길이에 맞게
   - **설명**: 부록 A 복사 → **타임라인을 최종 영상 기준으로 수정** → 링크·〈 〉 채우기
   - **썸네일**: 업로드
   - **재생목록**: "클로드 코드 입문" 같은 시리즈 재생목록을 만들어 추가 (다음 편과 묶기)
   - **시청자층**: **"아니요, 아동용이 아닙니다"** 선택
   - **더보기 → 태그**: `클로드 코드, 클로드코드, 클로드 사용법, 바이브코딩, 클로드 코워크, 왕초보` 정도 (태그의 영향은 크지 않으니 간단히)
   - **언어/카테고리**: 한국어 / 교육 또는 과학 기술
4. **변경된 콘텐츠(합성·AI) 표시 질문**이 나오면: 질문 문구를 **읽고 정직하게** 답하세요. ⚠ 실제 사람의 얼굴·목소리·실제 화면이면 보통 해당하지 않지만, 정확한 기준은 스튜디오의 안내와 공식 도움말에서 확인하세요.
5. **동영상 요소(Video elements)**
   - **최종 화면(End screen)**: 마지막 20초에 **구독 버튼 + 다음 영상/재생목록** 추가(엔드카드의 점선 박스 위치)
   - **카드**: 필요 시 치트시트 링크 카드(설명란 링크와 별도, ⚠ 외부 링크 카드는 조건이 있을 수 있음)
6. **검토**: 저작권 점검 결과 확인(배경음 문제 여부)
7. **공개 상태**: 처음에는 **"비공개"** 로 올려서 한 번 더 시청 → 문제없으면 **"예약"** 또는 **"공개"**

### 6-3. 공개 시점
- YouTube Studio의 **분석 → 시청자 → "시청자가 YouTube에 접속하는 시간"** 에서 구독자가 많이 접속하는 시간대를 보고 그 직전에 공개하세요. (구독자가 적으면 데이터가 없을 수 있어요. 그때는 저녁 시간 등으로 시작해 보고 데이터가 쌓이면 조정)

### 6-4. 공개 직후 할 일
1. 고정 댓글 올리기 (부록 B) → **고정** 처리
2. 설명란 링크가 **열리는지 직접 클릭**해서 확인
3. 영상을 처음부터 끝까지 **자막·소리 이상 없는지** 한 번 보기
4. 카카오/커뮤니티 등 내가 가진 채널에 공유
