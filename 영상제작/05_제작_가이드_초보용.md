### 1-2. 프로그램 (모두 무료 또는 무료 버전 있음) ⚠ 요금·기능은 확인

## 3단계. 화면 녹화 (OBS) — 클로드 데스크탑 앱

### 3-1. OBS 처음 설정 (한 번만) ⚠ 메뉴 이름은 버전마다 다를 수 있음
1. OBS를 설치하고 실행합니다.
2. 아래쪽 **소스(Sources)** 칸에서 **`+`** → **"창 캡처"(Window Capture)** 로 **클로드 앱 창**을 추가합니다(앱 창만 녹화. "화면 캡처"는 알림·다른 창이 찍힐 수 있어 피함). 폴더 탐색 장면(B12 분기 B, B16)은 해당 창을 따로 추가합니다.
3. **설정(Settings)** → **출력(Output)**: 녹화 형식 `mkv`(갑자기 꺼져도 파일 보존) → 끝난 뒤 `파일 → 녹화 리먹스(Remux)`로 mp4 변환. 또는 바로 `mp4`.
4. **설정 → 영상(Video)**: 기본 해상도·출력 해상도 모두 **1920×1080**, FPS **30**.
5. **설정 → 오디오**: **마이크·데스크톱 소리를 모두 끄고 영상만** 녹화합니다. 목소리는 AI 음성이 따로 깔립니다(앱 알림음이 섞이는 것도 방지).

### 3-2. 녹화 전 정리 (앱 기준) — 가릴 개인정보

| 할 일 | 이유 |
|---|---|
| 앱 **글자·화면 배율 키우기**(설정 위치는 앱 버전마다 달라 확인 필요. 안 되면 OS 화면 배율 또는 편집 때 확대) | 스마트폰 화면에서도 읽히게 |
| 사이드바의 **이전 세션 목록·프로젝트 이름** 가리기 (새 상태에서 시작하거나, 편집에서 블러) | 개인 작업·고객 정보 노출 방지 |
| **계정 이메일·이름·프로필**이 보이는 곳 가리기 | 개인정보 |
| 요금제·결제·사용량 화면의 **계정·결제 정보** 가리기 | 개인정보 |

| 바탕화면 아이콘·알림·메신저 끄기(앱 창만 녹화해도 알림 팝업은 찍힐 수 있음) | 개인정보, 집중 |

| **폴더 경로에 들어간 내 사용자 이름**(폴더 선택 창, 탐색기·파인더) 블러 | 개인정보 |
| 시연 폴더는 **새 빈 폴더**(`profit-calc`, `profit-calc-full`), 코워크는 **개인 파일 없는 폴더**(`cowork-practice`) | 개인 파일 노출 방지 |

| 폴더 선택 창, `@` 파일 목록에 **개인 폴더·파일 이름**이 보이는지 확인 | 개인정보 |
| **API 키·토큰·인증 코드**는 어디에도 화면에 나오지 않게 | 계정 보호 |
| 플러그인은 **공식 마켓플레이스 1개**만 설치하고 촬영 후 **삭제** | 안전 |

1. `자막/강조자막_초안.srt`는 ⚠ **이전 구성 기준이라 새 대본에 맞지 않습니다.** 새 대본의 `[자막]`(메인 대본)과 `06_샷리스트_편집타임라인.md` 2부 표의 자막 열에 맞게 다시 만드세요. 챕터 끝 **한 줄 요약 자막**(캡처·저장용)도 넣습니다.
2. 도식이 이미 보여 주는 문구(설치 3단계 등)는 겹치므로 지우세요.
3. 모양: **흰 글씨 + 검은 외곽선**, 크게, 화면 **아래 1/3**, 한 줄 **15자 내외**.
4. 안전 수칙(⑮·⑱)과 숫자(⑲ 정답, ⑳ 확인 기준)는 **오래, 크게** 유지합니다.

### 5-6. 소리 다듬기
- 챕터별 음량을 비슷하게 맞추기, 노이즈 제거는 보통 필요 없음(AI 음성)
- **새로 만든 음성(54문단)과 재사용 음성(42문단)은 만든 시기가 달라 음량·억양이 다를 수 있으니** 이어 붙인 경계(①②⑩ 챕터 안)를 특히 들어 보세요.
- 배경음은 말소리보다 **훨씬 작게**(말소리 구간에서 −20dB 정도). 배경음 없이도 됩니다.
- 유튜브는 소리를 자동으로 맞춥니다. ⚠ 흔히 −14 LUFS 부근을 기준으로 언급하지만 정확한 값은 확인하세요.

### 5-7. 배경음(BGM) 저작권 ⚠ 중요
가요·팝·영화 음악은 쓰지 마세요. **유튜브 스튜디오 오디오 보관함** 또는 **상업 이용 가능한 무료 음원**만, 이용 조건을 읽고 사용하세요.

### 5-8. 편집 감각 6가지 (30분 영상)
1. **처음 5초**에 결과물(계산기)이 나오게.
2. **30~40초마다 화면이 바뀌게** (앱 화면 → 도식 → 카드). 음성이 없는 긴 화면에는 작은 자막이나 줌인 이동을 넣어 멈춘 느낌을 줄이기.
3. 문단 사이 쉼은 너무 길면 줄이되 **0.4~0.6초는 남기기**.
4. 중요한 건 **크게, 한 번에 하나만**.
5. **줄이는 게 늘리는 것보다 낫습니다.** 확신 없는 부분은 뺍니다.
6. 30분 영상은 중간에 지치기 쉬우니 **10분·20분 재참여 장치(⑪, ⑲ 첫 문단)를 꼭 살립니다.** (효과는 보장되지 않으며, 업로드 후 시청 지속률로 확인합니다)

## 9. 막힐 때

- **OBS에 클로드 앱 창이 안 잡혀요(검은 화면)** → 소스를 "창 캡처"에서 "화면 캡처"로 바꾸거나 그 반대로 시도. 앱 창 크기를 바꿔 보기 ⚠ 환경마다 다름
- **앱에서 Code 탭이 안 열려요** → 유료 요금제 필요 안내일 수 있음. "온라인으로 로그인" 안내면 로그인 후 앱 재시작. 윈도우에서 "Git이 필요하다"는 안내가 뜨면 그때만 Git 설치(메인 대본 ③)
- **`+` 버튼이 안 보여요 (스킬·커넥터·플러그인 메뉴)** → 클라우드·WSL 세션에서는 `+` 버튼을 쓸 수 없습니다. **Local 세션**으로 새로 시작
- **내가 만든 스킬이 `/` 목록에 안 보여요** → 새 세션을 열어 다시 확인. `.claude/skills/스킬이름/SKILL.md` 위치와 파일 이름 확인(문서: 세션 중에 새로 만든 최상위 스킬 폴더는 `/reload-skills`가 필요)
- **코워크에서 내 스킬이 안 보여요** → 코워크는 내 컴퓨터의 스킬 폴더를 읽지 않고 Customize에 켜 둔 계정 스킬을 가져옵니다(대본 ⑭)
- **코워크 결과가 정답 표와 달라요** → 숨기지 말고 그대로 촬영하고 "그래서 검토가 필요하다"로 말한 뒤 `V19_p06`을 고쳐 다시 만들기
- **음성 생성이 "하루 무료 한도" 오류로 멈춰요** → 같은 명령을 한도가 풀린 뒤 다시 실행(이미 만든 파일은 건너뜀). 결제 연결 키인지 확인(11번 가이드 3-3)

- **업로드 후 화질이 낮아 보여요** → 처리(HD) 완료까지 기다리기

막히는 지점이 있으면 **어느 단계의 무엇이 안 되는지**와 **화면 캡처**(개인정보 가린 것)를 알려 주세요.
