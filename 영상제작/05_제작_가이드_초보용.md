# 영상 제작 가이드 — 유튜브 초보용 (처음부터 업로드까지)

> 이 가이드는 **"클로드 데스크탑 설치부터 클로드 코드 사용법까지"** 영상을 처음 만드는 사람을 위한 순서표입니다. 위에서부터 **차례로** 하세요.
> 이 영상은 **클로드 데스크탑 앱 하나**만 씁니다. VS Code·터미널·Node.js 설치나 `claude` 명령 입력은 **없습니다.**
> 이 영상은 **얼굴 없이 AI 음성 + 앱 화면 녹화**로 만듭니다(자세한 방식은 `11_인물없는_AI음성_제작가이드.md`). 이 문서는 공통 순서와 일반 내용을 다룹니다.
> 도구·메뉴·요금은 자주 바뀝니다. 화면이 조금 다르면 비슷한 이름의 메뉴를 찾으세요. 확인이 필요한 부분은 ⚠로 표시했습니다.

## 0. 전체 그림 (한눈에)

```
[1] 준비물 갖추기 → [2] 사실 확인·연습 → [3] 앱 화면 녹화(B1~B9) → [4] AI 음성 만들기
      → [5] 편집(음성 깔기·화면·도식·자막) → [6] 내보내기 → [7] 유튜브 업로드 → [8] 업로드 후 점검
```

| 단계 | 내가 할 일 | 걸리는 시간(처음, 어림값) |
|---|---|---|
| 1 | 프로그램 준비 | 1시간 |
| 2 | 사실 확인 + 연습 | 2~3시간 |
| 3 | 앱 화면 녹화 (B1~B9) | 1~2시간 |
| 4 | AI 음성 만들기 | 30분~1시간(대기·한도에 따라 다름) |
| 5 | 편집 | 4~8시간 |
| 6 | 내보내기 | 30분 |
| 7 | 업로드 설정 | 1시간 |
| 8 | 업로드 후 점검 | 24시간·72시간 후 각 15분 |

> 처음엔 오래 걸리는 게 정상입니다. 두 번째 영상부터 절반으로 줄어듭니다.

## 1단계. 준비물 갖추기

### 1-1. 장비

| 장비 | 꼭 필요? | 비고 |
|---|---|---|
| 컴퓨터 | 필수 | 앱 화면 녹화 + 편집용. **클로드 데스크탑 앱을 설치할 수 있는 PC** |
| 유료 요금제 계정 | 필수 | 코드·코워크 탭은 유료 요금제(Pro 이상) 필요(대본 ③). 챗은 모든 요금제. ⚠ 요금·한도는 공식 페이지에서 확인 |
| 헤드폰(이어폰) | 권장 | 음성·소리 확인용 |
| 마이크 | **선택** | AI 음성만 쓰면 불필요. 나중에 본인 목소리로 바꿀 때 필요 |
| 카메라·조명 | 불필요 | 얼굴이 나오지 않습니다 |

> 얼굴 촬영이 없는 대신 **화면이 읽히는지**가 품질의 절반입니다. 글자 크기와 가리기(3단계)에 시간을 쓰세요.

### 1-2. 프로그램 (모두 무료 또는 무료 버전 있음) ⚠ 요금·기능은 확인

| 용도 | 프로그램 | 이유 |
|---|---|---|
| 화면 녹화 | **OBS Studio** | 무료, 가장 널리 쓰임 |
| 편집·자막 | **Vrew(브루)** 또는 **CapCut(캡컷)**, 또는 다빈치 리졸브 | 한국어 자동 자막, 그래픽 얹기 |
| 음성 만들기 | `조립/make_voice.py` (Gemini 음성) | `11_인물없는_AI음성_제작가이드.md` 3장 |
| 영상·음성 처리 | ffmpeg, Python 3 | 조립 스크립트가 사용 ⚠ 설치 여부 확인 |

**처음이라면 추천 조합**: OBS(화면 녹화) + CapCut(이어 붙이기·그래픽·자막·내보내기). 자동 자막이 필요하면 Vrew를 더합니다.

### 1-3. 파일 정리 (이거 안 하면 편집 때 길을 잃습니다)

바탕화면에 **`클로드데스크탑영상`** 폴더를 만들고 아래 하위 폴더를 만드세요.

```
클로드데스크탑영상/
├─ 01_화면녹화/      (B1~B9)
├─ 02_음성/          (영상제작/음성 폴더의 V01_p00.mp3 …)
├─ 03_그래픽/        (그래픽/영상_mp4 의 도식 10개 + 챕터카드 폴더)
├─ 04_자막/          (강조자막_초안.srt)
├─ 05_음악/          (배경음)
├─ 06_편집프로젝트/
└─ 07_완성본/
```

**파일 이름 규칙**: `B6_코드탭첫세션_1.mp4`, `B8c_CLAUDEMD_1.mp4` 처럼 **번호_내용_순번**.

### 2-1. 사실 확인 (대본 부록 C·D)
`01_클로드데스크탑_클로드코드_메인대본.md` 맨 아래를 순서대로 확인하세요.

방법: **공식 문서**를 열어 보고, 내 컴퓨터의 앱에서 한 번씩 눌러 보세요. 다르면 **대본을 고치세요.**

### 2-2. 시연 연습 (B6 계산기)
앱에서 처음부터 끝까지 한 번 **끊지 않고** 해 보세요(앱 설치 → Code 탭 → 빈 폴더 `profit-calc` → 요청 → Accept → 결과 열기).

- 무료 계정이면 Code 탭에서 업그레이드 안내가 뜰 수 있습니다. 유료 계정으로 연습하세요.

### 2-3. 소리 내어 읽어 보기
`07_읽기용_대본.md`를 한 번 소리 내어 읽고 **입에 안 붙는 문장은 고치세요.** 고쳤다면 `10_AI음성_입력용_대본.md`에도 같은 곳을 반영해야 음성이 바뀝니다.

### 2-4. 길이 계산 (중요)
`10_AI음성_입력용_대본.md`는 총 약 3,800자이고 샘플 음성 기준 약 6.5자/초라 **대사만 약 9~10분**입니다. 여기에 쉼·챕터 카드·도식·엔드카드를 더하면 **약 11분 내외**(상세는 `06_샷리스트_편집타임라인.md` 3부)입니다.

- 정확한 길이는 음성 파일을 만든 뒤 **실제 파일 길이**로 다시 계산하세요.

## 3단계. 화면 녹화 (OBS) — 클로드 데스크탑 앱

### 3-1. OBS 처음 설정 (한 번만) ⚠ 메뉴 이름은 버전마다 다를 수 있음
1. OBS를 설치하고 실행합니다.
2. 아래쪽 **소스(Sources)** 칸에서 **`+`** → **"창 캡처"(Window Capture)** 로 **클로드 앱 창**을 추가합니다(앱 창만 녹화. "화면 캡처"는 알림·다른 창이 찍힐 수 있어 피함).
3. **설정(Settings)** → **출력(Output)**: 녹화 형식 `mkv`(갑자기 꺼져도 파일 보존) → 끝난 뒤 `파일 → 녹화 리먹스(Remux)`로 mp4 변환. 또는 바로 `mp4`.
4. **설정 → 영상(Video)**: 기본 해상도·출력 해상도 모두 **1920×1080**, FPS **30**.
5. **설정 → 오디오**: **마이크·데스크톱 소리를 모두 끄고 영상만** 녹화합니다. 목소리는 AI 음성이 따로 깔립니다(앱 알림음이 섞이는 것도 방지).

### 3-2. 녹화 전 정리 (앱 기준)

| 할 일 | 이유 |
|---|---|
| 앱 **글자·화면 배율 키우기**(설정 위치는 앱 버전마다 달라 확인 필요. 안 되면 OS 화면 배율 또는 편집 때 확대) | 스마트폰 화면에서도 읽히게 |
| 사이드바의 **이전 세션 목록·프로젝트 이름** 가리기 (새 상태에서 시작하거나, 편집에서 블러) | 개인 작업·고객 정보 노출 방지 |
| **계정 이메일·이름·프로필**이 보이는 곳 가리기 | 개인정보 |
| 요금제·결제·사용량 화면의 **계정·결제 정보** 가리기 | 개인정보 |
| 로그인 장면에서 **이메일·비밀번호 입력 모습은 찍지 않기** | 계정 보호 |
| 바탕화면 아이콘·알림·메신저 끄기(앱 창만 녹화해도 알림 팝업은 찍힐 수 있음) | 개인정보, 집중 |
| 시연 폴더 `profit-calc`는 **새 빈 폴더**, 코워크는 **개인 파일 없는 폴더** | 개인 파일 노출 방지 |
| 시연 데이터는 **가짜 숫자**만 | 사실·안전 |
| 폴더 선택 창, `@` 파일 목록에 **개인 폴더·파일 이름**이 보이는지 확인 | 개인정보 |

### 3-3. 녹화 순서
`06_샷리스트_편집타임라인.md`의 **B1~B9** 항목을 보고, 항목마다 무엇을 켜서 무엇을 보여 줄지 확인한 뒤 찍습니다. 클립마다:
1. 녹화 시작 → **3초 가만히** → 시연 → **3초 가만히** → 녹화 중지
2. 틀렸으면 **그 클립만** 다시
3. 파일 이름을 바로 `B6_코드탭첫세션_1.mp4`처럼 바꿔 `01_화면녹화`에 저장

## 4단계. AI 음성 만들기

얼굴·본인 녹음이 없으므로 음성은 `10_AI음성_입력용_대본.md`로 만듭니다. 방법·무료 한도·파일명은 **`11_인물없는_AI음성_제작가이드.md` 3장**을 따르세요. 한 줄 요약:

```
python 조립/make_voice.py --voice Kore        # 챕터당 1회 요청, 문단별 파일 음성/V01_p00.mp3 …
```

완성 후 이어폰으로 처음부터 끝까지 들어 보고, 어색한 단어는 입력용 대본의 발음 표기를 고쳐 다시 만드세요.
> 본인 목소리로 바꾸고 싶다면 `07_읽기용_대본.md`를 챕터·문단별로 읽어 같은 파일명으로 저장하면 이후 과정은 동일합니다.

## 5단계. 편집 (순서대로)

### 5-1. 큰 흐름
```
(1) 음성 파일을 시간순으로 올리기(줄기) → (2) 앱 화면 녹화 얹기 → (3) 도식·챕터 카드 넣기
→ (4) 강조 자막·대사 자막 → (5) 소리 다듬기 → (6) 배경음(선택) → (7) 확인 → (8) 내보내기
```
각 구간에 무엇을 쓰는지는 `06_샷리스트_편집타임라인.md` 2부 표를 따릅니다.

### 5-2. CapCut으로 "이어 붙이기 + 그래픽 얹기"
1. CapCut을 실행 → **새 프로젝트**. 비율 **16:9**.
2. **미디어 가져오기**: `01_화면녹화`, `02_음성`, `03_그래픽`의 mp4를 모두 불러옵니다.
3. 타임라인에 **음성(V01_p00 …)** 을 순서대로 올립니다(문단 사이 약 0.6초 쉼).
4. 앱 화면 녹화(B)를 타임라인 표대로 **위 트랙에 올려** 해당 문단을 덮습니다.
5. 도식·챕터 카드를 같은 표대로 올립니다.
6. 긴 대기(설치·생성 중)는 **클립 속도 2~4배**로 줄입니다. 배속 구간에 작은 자막으로 알립니다.
7. 앱 화면에서 중요한 부분은 **확대(줌인)** 하고, 가릴 곳은 **블러·모자이크** 처리합니다.
8. 음성보다 화면이 길면 배속·자르기, 짧으면 마지막 프레임 정지·확대·도식 이어 붙이기.

### 5-3. 대사 자막 (Vrew 또는 CapCut 자동 자막)
음성이 있으므로 편집 프로그램의 **자동 자막**으로 만든 뒤 **틀린 글자를 직접 고칩니다.** 영어 이름(CLAUDE.md, Accept 등)은 특히 오타가 많습니다. ⚠ 메뉴·요금은 확인.

### 5-4. 강조 자막 넣기
1. `자막/강조자막_초안.srt`는 ⚠ **이전 대본(터미널 방식) 기준일 수 있습니다.** 새 대본의 `[자막]`(메인 대본)과 `06_샷리스트_편집타임라인.md` 표의 자막 열에 맞게 고쳐 쓰세요.
2. 도식이 이미 보여 주는 문구(설치 3단계 등)는 겹치므로 지우세요.
3. 모양: **흰 글씨 + 검은 외곽선**, 크게, 화면 **아래 1/3**, 한 줄 **15자 내외**.

### 5-5. 소리 다듬기
- 챕터별 음량을 비슷하게 맞추기, 노이즈 제거는 보통 필요 없음(AI 음성)
- 배경음은 말소리보다 **훨씬 작게**(말소리 구간에서 −20dB 정도). 배경음 없이도 됩니다.
- 유튜브는 소리를 자동으로 맞춥니다. ⚠ 흔히 −14 LUFS 부근을 기준으로 언급하지만 정확한 값은 확인하세요.

### 5-6. 배경음(BGM) 저작권 ⚠ 중요
가요·팝·영화 음악은 쓰지 마세요. **유튜브 스튜디오 오디오 보관함** 또는 **상업 이용 가능한 무료 음원**만, 이용 조건을 읽고 사용하세요.

### 5-7. 편집 감각 5가지
1. **처음 5초**에 결과물(계산기)이 나오게.
2. **30~40초마다 화면이 바뀌게** (앱 화면 → 도식 → 카드).
3. 문단 사이 쉼은 너무 길면 줄이되 **0.4~0.6초는 남기기**.
4. 중요한 건 **크게, 한 번에 하나만**.
5. **줄이는 게 늘리는 것보다 낫습니다.** 확신 없는 부분은 뺍니다.

### 5-8. 내보내기 ⚠ 메뉴 이름은 다를 수 있음

| 형식 | MP4 (H.264) |

### 6-1. 올리기 전 준비물 체크

- [ ] 제목, 설명란, 고정 댓글 (`01_클로드데스크탑_클로드코드_메인대본.md` 부록 A·B)

- [ ] 설명란 타임라인을 **최종 영상 기준으로 다시 쓰기**

- [ ] **AI 음성 고지 문구**(설명란) — `11_인물없는_AI음성_제작가이드.md` 7장

### 6-2. 업로드 순서
1. youtube.com 로그인 → **만들기(+) → 동영상 업로드** → 파일 끌어놓기
2. **세부정보**
   - **제목**(안): `2026 클로드 데스크탑 설치부터 클로드 코드 사용법까지｜챗·코워크·코드 15분 총정리 (왕초보 · 무료 치트시트)` ⚠ 실제 길이에 맞게
   - **설명**: 부록 A 복사 → 타임라인 수정 → 링크·〈 〉 채우기 → AI 음성 고지 추가
   - **썸네일** 업로드 / **재생목록**: "클로드 코드 입문" 같은 시리즈(다음 편과 묶기)
   - **시청자층**: **"아니요, 아동용이 아닙니다"**
   - **태그**(영향은 크지 않음): `클로드 데스크탑, 클로드 코드, 클로드 사용법, 클로드 코워크, 왕초보`
   - **언어/카테고리**: 한국어 / 교육 또는 과학 기술
3. **변경된 콘텐츠(합성·AI) 질문**: 문구를 읽고 **정직하게** 답하세요. ⚠ AI 음성이 실제 사람처럼 들리면 표시 대상이 될 수 있으니 스튜디오 안내와 공식 도움말에서 기준을 확인하세요.
4. **동영상 요소**: **최종 화면** 마지막 20초에 구독 버튼 + 다음 영상/재생목록(엔드카드 `10_엔드카드_20초`의 위치에 맞춤). 카드는 필요 시(외부 링크 카드는 조건이 있을 수 있음 ⚠).
5. **검토**: 저작권 점검 결과 확인(배경음)
6. **공개 상태**: 처음에는 **"비공개"** 로 올려서 한 번 더 시청 → 문제없으면 **"예약"** 또는 **"공개"**

### 6-3. 공개 시점
YouTube Studio **분석 → 시청자** 에서 시청자가 접속하는 시간대를 보고 그 직전에 공개하세요. 데이터가 없으면 저녁 시간대로 시작해 보고 조정합니다.

### 6-4. 공개 직후 할 일

3. 영상을 처음부터 끝까지 한 번 보기
