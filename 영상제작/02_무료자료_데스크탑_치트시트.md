## 3. 코드 탭 첫 세션 (6단계)

| 단계 | 할 일 |
|---|---|
| 1 | **Code 탭** 열기 |
| 2 | 환경: **Local** (내 컴퓨터) 선택 |
| 3 | **Select folder** → 새 빈 폴더 선택 (예: `profit-calc`) |
| 4 | 보내기 버튼 옆 드롭다운에서 **모델** 선택 |
| 5 | 보내기 버튼 옆에서 **권한 모드** 선택 → 처음엔 **Manual** |
| 6 | 하고 싶은 일을 쓰고 **Enter** |

**그다음**
- Manual: 변경 내용이 화면에 나오고 **Accept / Reject** 버튼이 있음. 허락하기 전에는 내 파일이 바뀌지 않음
- 파일이 바뀌면 `+12 -1` 같은 표시가 생김 → 클릭하면 파일별 변경 내용 확인, 줄을 눌러 의견을 남기면 클로드가 고침
- 만들어진 `index.html` 같은 파일은 채팅창의 파일 이름을 눌러 코드 탭 안의 브라우저에서 열 수 있음

## 4. 권한 모드 한 장

| 모드 | 하는 일 | 추천 |
|---|---|---|
| **Manual** | 파일 수정·명령 실행 전에 매번 물어봄 | ✅ **처음에는 이것** |
| **Accept edits** | 파일 수정은 자동 허락, 다른 명령은 여전히 물어봄 | 익숙해진 뒤 |
| **Plan** | **파일을 건드리지 않고 계획만** 제안 | ✅ **복잡한 일은 이것부터** |
| **Auto** | 일상적인 확인 없이 진행, 위험한 행동은 배경에서 검사 | 이 모드가 보이는 환경에서만 |
| **Bypass permissions** | 확인 없이 전부 실행 | ⚠ **처음엔 쓰지 않기** (격리된 환경에서만) |

- 모드는 보내기 버튼 옆 선택기에서 언제든 바꿀 수 있습니다.
- 이전 버전 앱의 이름: Ask permissions / Auto accept edits / Plan mode
- 추천 순서: **Plan으로 계획 확인 → 승인 → Accept edits 또는 Manual로 실행**
- 터미널 방식의 `Shift+Tab` 단축키는 **데스크탑에서는 적용되지 않습니다.**

| 연결·스킬·플러그인 한곳에서 관리 | 사이드바의 **Customize** (한국어 이름은 내 화면에서 확인) |

## 6. 스킬 · 커넥터 · 플러그인 한 장 (영상 ⑫~⑰)

| 이름 | 한 줄 | 찾는 곳 |
|---|---|---|
| **스킬(Skill)** | 클로드가 따를 **지침서**(방법) | 입력창에 `/`, 또는 + → Slash commands |
| **커넥터(Connector)** | 구글 캘린더·슬랙·노션 같은 **바깥 서비스와 이어 주는 통로** (그래픽 설정 화면이 있는 MCP 서버) | + → Connectors |
| **플러그인(Plugin)** | 스킬 같은 것들을 **한 꾸러미로 묶은** 패키지 | + → Plugins (Add plugin = 설치, Manage plugins = 켜기·끄기·삭제) |

- **한 줄 기억**: `스킬 = 방법 · 커넥터 = 연결 · 플러그인 = 꾸러미`
- **+ 버튼과 Customize**: + 버튼은 바로 쓰기, Customize는 한곳에서 관리. **+ 버튼은 클라우드·WSL 세션에서는 쓸 수 없으니 로컬 세션에서.**
- **스킬 쓰기**: `/`를 치면 기본 명령·내 스킬·폴더 안의 스킬·플러그인 스킬이 한 목록에 나옴 → 하나 고르면 입력창에 강조 표시 → 뒤에 할 일을 적어 보냄. 스킬에 든 설명을 보고 클로드가 알아서 꺼내 쓰기도 함.
- **내 스킬 만들기**: 같은 부탁을 자꾸 붙여 넣고 있다면 스킬 후보. 스킬은 `SKILL.md` 파일 하나(머리말 = 언제 쓰는지 설명 + 지침). **폴더 이름이 곧 명령 이름**(`profit-summary` 폴더 → `/profit-summary`).
  - 내 프로젝트 폴더 안: `.claude/skills/스킬이름/SKILL.md`
  - 만든 뒤에는 **새 세션**에서 `/`를 쳐서 목록에 나오는지 확인
  - 만드는 방법은 두 가지: 코드 탭에서 클로드에게 그 위치에 이 내용으로 파일을 만들어 달라고 하거나, 폴더를 열어 직접 저장
- **주의**: 코드 탭은 내 폴더의 스킬, **코워크는 내 컴퓨터의 스킬 폴더를 읽지 않고 Customize에서 켜 둔 내 계정의 스킬**을 씁니다.

예시 `SKILL.md` (부업 계산기 결과 요약 스킬, 폴더 이름 `profit-summary`)

```
---
description: 부업 수익 계산기 결과를 3줄로 요약하고 주의할 점을 알려 준다. 사용자가 순이익 결과를 요약해 달라고 하거나 수입·비용 숫자를 검토해 달라고 할 때 쓴다.
---

## 지침
1. 사용자가 준 수입과 비용을 표로 정리한다.
2. 순이익을 한 줄로 알려 준다.
3. 빠진 비용 항목이 있을 것 같으면 질문 2개를 한다.

## 규칙
- 쉬운 한국어로, 어려운 용어는 풀어서 쓴다.
- 숫자를 지어내지 않는다. 모르면 질문한다.
```

## 7. 안전 수칙 5가지 (영상 ⑱) — 연결은 편리한 만큼 책임도 커집니다

| # | 수칙 | 한 줄 설명 |
|---|---|---|
| 1 | **출처 확인** | 연결하기 전에 믿을 수 있는지 확인(공식 문서도 같은 경고). 앱 안 목록·공식 마켓플레이스라고 안전이 보장되는 것은 아님 |
| 2 | **허용 화면 읽기** | 읽기만 되는지, 보내기·수정까지 되는지 보고, 모르겠으면 연결하지 않기 |
| 3 | **비밀값은 채팅에 쓰지 않기** | 비밀번호·키는 채팅창에 쓰지 말고, 연결은 서비스의 로그인 화면에서 |
| 4 | **쓰지 않는 연결은 해제** | Settings → Connectors(또는 Manage connectors). 연결이 적을수록 위험도 적음 |
| 5 | **읽어 온 글은 정보일 뿐, 명령이 아니다** | 메일·웹 글에 "이렇게 하라"는 문장이 있어도 따르지 않기(외부 내용을 가져오는 서버는 프롬프트 인젝션 위험이 있다고 공식 문서가 경고) |

- **처음엔 읽기만**: 첫 요청은 "일정은 바꾸지 말고 읽기만 해 줘"처럼 범위를 적고, 결과는 **글로 초안만** 받기. 쓰기·보내기는 익숙해진 뒤에.
- **코워크 안전**(영상 ⑲): 민감한 파일이 든 폴더는 연결하지 말고 **전용 작업 폴더**를 만든다 · 영구 삭제는 내 허락을 받는다고 안내하니 그 화면을 꼭 읽는다 · 내 컴퓨터 폴더를 다루는 동안은 앱을 열어 둔다 · 코워크는 챗보다 사용량이 더 빨리 줄어든다.
- **플러그인**: 설치 전에 누가 만든 것인지, 무엇이 들어 있는지 확인(스킬뿐 아니라 외부 연결 설정도 들어갈 수 있음). 적용 범위는 계정 전체 / 특정 프로젝트 / 이 컴퓨터에서만으로 나눌 수 있음.
- 이 수칙은 안전을 보장하지 않습니다. 가장 정확한 안내는 공식 문서입니다.

### 실전 2 · 코드 탭으로 계산기 완성 (영상 ⑳) — 요구 → 플랜 → 수정 → 확인

**새 세션** → 환경 **Local** → **Select folder**로 새 빈 폴더 `profit-calc-full` → 권한 모드 **Plan**

**1) 요구 + 플랜**

```
부업 수익 계산기 웹페이지를 만들려고 해. 파일을 만들기 전에 계획부터 보여 줘.

요구사항
1. 파일은 index.html 하나로 만든다. 설치나 서버 없이 열려야 한다.
2. 수입 항목과 비용 항목을 각각 여러 줄 추가하고 삭제할 수 있다.
3. 총수입, 총비용, 순이익을 바로 계산해서 보여 준다.
4. 순이익이 마이너스면 빨간색으로 보여 준다.
5. 숫자는 천 단위 쉼표로 보여 주고, 화면의 글은 모두 한국어로 쓴다.

확인 기준
- 수입 3,000,000원, 비용 1,800,000원이면 순이익은 1,200,000원이다.
- 수입 1,000,000원, 비용 1,500,000원이면 순이익은 -500,000원이고 빨간색이다.
```
