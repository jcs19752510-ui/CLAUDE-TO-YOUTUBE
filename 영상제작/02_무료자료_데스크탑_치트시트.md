# 🎁 무료 치트시트 — 클로드 데스크탑 앱 + 코드 탭

> 메인 영상(`01_클로드데스크탑_클로드코드_메인대본.md`)에서 약속한 자료입니다. 인쇄하거나 캡처해 두고 쓰세요.
> 내용은 **2026-10-07에 읽은 Anthropic 공식 문서**에 근거합니다. 앱은 업데이트되므로 화면이 다르면 공식 문서를 확인하세요. (`code.claude.com/docs/en/desktop`)

## 1. 설치와 로그인 (5분)

```
1) 공식 다운로드 페이지(claude.com/download)에서 내 컴퓨터용 설치 파일 받기
   - 맥: Download for macOS
   - 윈도우: 마이크로소프트 스토어 또는 직접 다운로드
2) 설치 후 앱 실행 (맥: 응용 프로그램 폴더 / 윈도우: 시작 메뉴 → Claude)
3) 클로드 계정으로 로그인
4) 상단 가운데의 Code 탭 클릭
```

| 알아둘 것 | 내용 |
|---|---|
| 요금제 | **Chat은 무료 포함 모든 요금제.** Code·Cowork은 **Pro, Max, Team, Enterprise** 필요 |
| 업그레이드 안내가 뜰 때 | 유료 요금제 가입이 필요하다는 뜻 |
| 온라인 로그인 안내가 뜰 때 | 안내대로 로그인을 마친 뒤 **앱을 다시 시작** |
| 따로 설치할 것 | **없음.** 데스크탑 앱에 Claude Code가 포함되어 있어 Node.js·CLI·터미널이 필요 없음 |
| "Git이 필요하다"는 오류 | 그때만 Git 설치 (윈도우는 Git for Windows) |

## 2. 세 개의 탭, 뭘 눌러야 할까?

| 원하는 것 | 탭 | 설명 |
|---|---|---|
| 답·생각 정리 | **Chat** | 파일 접근 없는 일반 대화 |
| 일을 통째로 맡기기 | **Cowork** | 목표를 맡기면 파일·도구로 작업해 검토할 결과물을 제공 |
| 계속 쓸 웹사이트·앱·도구 | **Code** | 내 컴퓨터 폴더의 파일을 직접 만들고 고침 |

## 3. 코드 탭 첫 세션 (6단계)

| 단계 | 할 일 |
|---|---|
| 1 | **Code 탭** 열기 |
| 2 | 환경: **Local** (내 컴퓨터) 선택 |
| 3 | **Select folder** → 새 빈 폴더 선택 (예: `profit-calc`) |
| 4 | 보내기 버튼 옆 드롭다운에서 **모델** 선택 |
| 5 | 보내기 버튼 옆에서 **권한 모드** 선택 → 처음엔 **Manual** |
| 6 | 하고 싶은 일을 쓰고 **Enter** |

**그다음**
- Manual: 변경 내용이 화면에 나오고 **Accept / Reject** 버튼이 있음. 허락하기 전에는 내 파일이 바뀌지 않음
- 파일이 바뀌면 `+12 -1` 같은 표시가 생김 → 클릭하면 파일별 변경 내용 확인, 줄을 눌러 의견을 남기면 클로드가 고침

## 4. 권한 모드 한 장

| 모드 | 하는 일 | 추천 |
|---|---|---|
| **Manual** | 파일 수정·명령 실행 전에 매번 물어봄 | ✅ **처음에는 이것** |
| **Accept edits** | 파일 수정은 자동 허락, 다른 명령은 여전히 물어봄 | 익숙해진 뒤 |
| **Plan** | **파일을 건드리지 않고 계획만** 제안 | ✅ **복잡한 일은 이것부터** |
| **Auto** | 일상적인 확인 없이 진행, 위험한 행동은 배경에서 검사 | 이 모드가 보이는 환경에서만 |
| **Bypass permissions** | 확인 없이 전부 실행 | ⚠ **처음엔 쓰지 않기** (격리된 환경에서만) |

- 모드는 보내기 버튼 옆 선택기에서 언제든 바꿀 수 있습니다.
- 이전 버전 앱의 이름: Ask permissions / Auto accept edits / Plan mode
- 추천 순서: **Plan으로 계획 확인 → 승인 → Accept edits 또는 Manual로 실행**
- 터미널 방식의 `Shift+Tab` 단축키는 **데스크탑에서는 적용되지 않습니다.**

## 5. 자주 쓰는 동작

| 하고 싶은 일 | 방법 |
|---|---|
| 멈추기 | **정지 버튼** 또는 `Esc` |
| 멈추지 않고 방향 바꾸기 | 입력창에 고칠 내용을 쓰고 **Enter** |
| 파일 지정 | 입력창에 `@파일이름` |
| 이미지·PDF 보여주기 | 첨부 버튼 또는 **끌어다 놓기** |
| 사용량 확인 | 모델 선택기 옆 **원형 표시** 클릭 (기억 공간 + 요금제 사용량) |
| 대화 요약 | 가득 차면 자동 요약 / 미리 하려면 `/compact` |
| 명령 목록 | 입력창에 `/` 또는 `+` → Slash commands |
| 파일 첨부·스킬·커넥터·플러그인 | 입력창의 **+ 버튼** |
| 새 작업 시작 | **+ New session** (`Ctrl+N` / 맥은 `Cmd+N`) |
| 질문만 따로 | 사이드 챗 (`Ctrl+;` / 맥은 `Cmd+;`, 또는 `/btw`) |
| 변경 내용 창 열고 닫기 | `Ctrl+Shift+D` / 맥은 `Cmd+Shift+D` |
| **단축키 전체 보기** | `Ctrl+/` / 맥은 `Cmd+/` |
| 연결·스킬·플러그인 한곳에서 관리 | 사이드바의 **Customize**(한국어 화면에서는 "사용자 지정") |

## 6. 첫 프롬프트 예시 (복붙용)

```
부업 수익 계산기 웹페이지 만들어 줘.
수입과 비용을 입력하면 순이익이 바로 나오게 해 줘.
```

```
(Plan 모드에서)
수익 계산기에 월별 기록을 저장하는 기능을 추가하고 싶어.
어떻게 만들면 좋을지 계획만 먼저 보여 줘.
```

```
이 폴더에 대한 지침이 담긴 CLAUDE.md 파일을 만들어 줘.
모든 답변과 설명은 한국어로, 어려운 용어는 쉬운 말로 풀어서 써 줘.
```

## 7. 업무 지침서 `CLAUDE.md` 시작 예시

> 클로드가 일을 시작할 때 읽는 지침 파일입니다. 위 프롬프트로 만들게 한 뒤, 아래 줄을 필요한 만큼 추가하세요.

```markdown
## 작업 규칙
- 모든 답변과 설명은 한국어로 한다.
- 어려운 용어는 쉬운 말로 한 줄 풀이를 덧붙인다.
- 파일을 바꾸기 전에 무엇을 바꿀지 먼저 말한다.
- 한 번에 한 가지씩 작게 작업한다.
- 작업이 끝나면 무엇을 바꿨는지 세 줄 이내로 요약한다.
```

## 8. 초보 실수 3가지

| # | 실수 | 이렇게 하세요 |
|---|---|---|
| 1 | 처음부터 **Bypass** 같은 확인 없는 모드 사용 | 처음엔 **Manual**, 큰일은 **Plan** |
| 2 | 한 번에 너무 큰 요청 | 작게 쪼개고, 복잡하면 Plan에서 계획부터 |
| 3 | 한 세션에 여러 일을 섞음 | 일마다 **새 세션** |

## 9. 막혔을 때

- [ ] Code 탭에서 업그레이드 안내 → 유료 요금제(Pro 이상) 필요
- [ ] 온라인 로그인 안내 → 로그인 완료 후 **앱 재시작**
- [ ] "Git is required" → Git 설치(윈도우는 Git for Windows) 후 다시 시도
- [ ] 로그인 관련 403 오류 → 공식 문서의 인증 문제 해결 안내 확인
- [ ] 화면이 비어 있거나 멈춤 → 앱을 완전히 종료한 뒤 다시 실행
