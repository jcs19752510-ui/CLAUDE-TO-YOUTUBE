**이 편의 차별점**
1. ②는 설명 위주(앱 화면) → 여기서는 **파일을 직접 만들고 직접 연결**한다.
2. ①은 소개만 하고 끝 → 여기서는 **완성된 스킬을 한 번 쓰고, 한 번 고치는 과정**까지 보여 준다.
3. 셋 다 **외부 도구 연결의 위험**을 거의 다루지 않음 → **안전 수칙 5가지** 챕터를 둔다.
4. 마지막에 **"오늘 만들 스킬 1개"** 를 명확히 준다.
