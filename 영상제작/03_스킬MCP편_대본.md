# 클로드 스킬·커넥터(MCP) 쓰는 법 — 2편 전체 대본 (15분, 데스크탑 앱 기준)

- **제목 후보 3개**
  1. `클로드 스킬·커넥터 15분 총정리｜한 번 가르치면 계속 써먹는다 (데스크탑 앱 · 왕초보 · 무료 안전 체크리스트)`
  2. `클로드한테 내 구글 캘린더·슬랙 연결하는 법｜커넥터 설정부터 안전 수칙까지`
  3. `반복 작업은 '스킬'로 끝내세요｜클로드 데스크탑 스킬·커넥터·플러그인 한 번에 이해`
- **대상**: 1편을 본(또는 앱을 설치한) AI 왕초보 일반 사용자
- **촬영 환경**: **클로드 데스크탑 앱만** 사용. VS Code, 터미널, Node.js **없음**. `claude mcp add` 같은 터미널 명령은 **이 영상에서 쓰지 않습니다.**
- **표기**: **[화면]** 보여줄 것 · **[말]** 그대로 읽는 대사 · **[자막]** 큰 글씨 · **[편집]** 컷·효과 · `⟲` 시청 유지 장치 · `〈 〉` 본인이 채울 칸

> **이 대본의 사실은 2026-10-07에 읽은 Anthropic 공식 문서(code.claude.com/docs/en/desktop, /skills, /mcp)에 근거합니다.** 근거와 "문서에서 확인하지 못한 것"은 부록 C에 있습니다. 한국어 메뉴 이름은 실제 화면과 다를 수 있어 **공식 영어 이름 + 한국어 설명**으로 적었습니다(예: Customize = 한국어 UI '사용자 지정'). 촬영 때는 **화면에 보이는 이름 그대로** 말해 주세요.

## 0. 구성 원칙

| 항목 | 내용 |
|---|---|
| 이어 쓰는 프로젝트 | 1편의 **'부업 수익 계산기'** 폴더(`profit-calc`) |
| 핵심 메시지 | 스킬 = 일하는 **방법**을 가르치기 / 커넥터 = 밖의 **도구**에 연결하기 |
| 금지 | 터미널 명령, 확인 안 된 메뉴 경로 단정, 요금 금액 단정, "100% 안전" 같은 과장 |
| 안전 | 챕터 ⑨ 전용 + 연결 챕터마다 짧은 경고 |

## ① 하이라이트 (0:00 ~ 0:25)

**[화면]** 클로드 데스크탑 앱 Code 탭. 입력창에 한 줄 입력 후 Enter.
`〈연결해 둔 캘린더에서 이번 주 일정 3개만 읽어서 알려 줘〉`
**[편집]** 가속 → 클로드가 일정을 읽어 와서 답하는 장면. (**개인 일정은 가짜 일정으로 준비**)
**[말]**
"이 일정은 제가 캘린더를 열지 않고, 클로드에게 말 한 줄 해서 가져온 겁니다. 터미널도 안 열었고, 앱 안에서 버튼 몇 번 누른 게 전부예요."
**[자막]** `앱 안에서 · 버튼 몇 번 · 터미널 없이`
**[말]**
"오늘은 클로드에게 **일하는 방법을 가르치는 스킬**, 그리고 **밖의 도구와 연결하는 커넥터**를 15분 안에 알려 드립니다. 안전하게 쓰는 법을 담은 체크리스트는 설명란에 있어요."
**[편집]** 타이틀 카드 1.5초 → 인트로.

## ② 통증 + 약속 (0:25 ~ 1:15)

**[화면]** 얼굴 또는 앱 화면 위 자막.
**[말]**
"클로드를 쓰다 보면 이런 일이 생깁니다. 어제 시킨 일을 오늘 또 똑같이 설명해야 하고, 다른 프로그램에 있는 내용을 복사해서 붙여 넣어야 하죠."
**[자막]** `매번 같은 설명 · 복사해서 붙여넣기`
**[말]**
"앞의 문제는 **스킬**이, 뒤의 문제는 **커넥터**가 해결해 줍니다. 공식 문서 말로는, 다른 도구에서 데이터를 자꾸 복사해 채팅에 붙여 넣고 있다면 연결을 고려할 때라고 해요."
**[말]**
"오늘 순서는 이렇습니다. 첫째, 스킬이 뭔지 알고 써 봅니다. 둘째, 내 스킬을 만드는 방법을 봅니다. 셋째, 커넥터를 연결해서 일을 시켜 봅니다. 마지막으로, 연결할 때 꼭 지켜야 할 안전 수칙을 알려 드릴게요."
**[화면]** 3칸 지도: `① 스킬` → `② 커넥터` → `③ 안전`
⟲ **[말, 1:10]**
"1편에서 만든 부업 수익 계산기 폴더를 이어서 쓸 거예요. 아직 안 만드셨다면 1편을 먼저 보고 오셔도 좋습니다."

## ③ 스킬·커넥터·플러그인, 한 줄 구분 + 어디 있나 (1:15 ~ 3:15)

**[화면]** 3칸 그래픽.
**[말]**
"용어가 세 개 나옵니다. 한 줄씩 구분할게요."

| 이름(자막) | 한 줄 설명(말) |
|---|---|
| **스킬(Skill)** | "클로드가 따를 **지침서**예요. 지침이 적힌 파일 하나를 만들어 두면, 클로드가 필요할 때 꺼내 쓰고, 내가 직접 불러 쓸 수도 있습니다." |
| **커넥터(Connector)** | "구글 캘린더, 슬랙, 깃허브, 리니어, 노션 같은 **밖의 서비스와 연결**하는 통로예요. 공식 문서 말로는 **그래픽 설정 화면이 있는 MCP 서버**입니다." |
| **플러그인(Plugin)** | "스킬, 에이전트, 연결 설정 등을 **한 꾸러미로 묶은 패키지**예요. 앱에서 골라서 설치할 수 있습니다." |

**[자막]** `스킬 = 방법 · 커넥터 = 연결 · 플러그인 = 꾸러미`
**[말]**
"MCP라는 말이 어렵게 들리죠? 서비스와 클로드를 이어 주는 **공통 규격**이라고만 알아 두세요. 앱에서는 커넥터라는 이름의 버튼으로 쓰니까, 규격 이름은 몰라도 됩니다."

**[화면]** 입력창 옆 **+** 버튼을 누른다. 메뉴에서 파일 첨부, Slash commands, Connectors, Plugins 항목을 하나씩 짚는다. 〈실제 화면의 메뉴 이름 그대로 촬영〉
**[말]**
"첫 번째 위치, **입력창 옆 더하기 버튼**입니다. 여기서 파일 첨부, 스킬이 들어 있는 슬래시 명령, 커넥터, 플러그인에 갈 수 있어요."
**[화면]** 왼쪽 사이드바의 **Customize**(한국어 '사용자 지정')를 클릭.
**[말]**
"두 번째 위치는 사이드바의 **사용자 지정**, 영어로 Customize예요. 커넥터, 스킬, 플러그인을 **한곳에서 관리**하는 곳입니다."
**[자막]** `+ 버튼 = 바로 쓰기 · Customize = 한곳에서 관리`

⟲ **[말, 3:10]**
"먼저 이미 있는 스킬을 불러 써 볼게요. 키보드에서 슬래시 한 번만 누르면 됩니다."

> 근거: 데스크탑 문서 "Extend Claude Code"(Customize 한곳 관리), "Connect external tools"(+ 버튼, 커넥터는 그래픽 설정 흐름이 있는 MCP 서버), "Install plugins"(플러그인 정의).
> 촬영 주의: **+ 버튼은 클라우드·WSL 세션에서는 쓸 수 없습니다.** 반드시 **Local 세션**으로 촬영하세요.

## ④ 슬래시(/)로 스킬 써 보기 (3:15 ~ 4:45)

**[화면]** Code 탭, 1편의 `profit-calc` 폴더 세션. 입력창에 `/` 입력 → 목록이 뜬다.
**[말]**
"입력창에 슬래시를 치면 목록이 나옵니다. 클로드가 기본으로 가진 명령, 내가 만든 스킬, 폴더에 들어 있는 스킬, 설치한 플러그인의 스킬이 **다 여기 모여 있어요**. 더하기 버튼에서 Slash commands를 골라도 같은 목록이 열립니다."
**[화면]** 목록에서 하나 선택 → 입력창에 강조 표시 → 뒤에 할 일을 쓰고 Enter.
`〈촬영 때 실제로 목록에 있는 스킬 중 안전한 것을 하나 골라 시연. 예: 코드 검토 계열 명령〉`
**[말]**
"하나 고르면 입력창에 이렇게 **강조 표시**가 됩니다. 그 뒤에 할 일을 적고 보내면 돼요. 이게 스킬을 **내가 직접 부르는** 방법입니다."
**[말]**
"직접 안 불러도 됩니다. 스킬에는 '언제 쓰는 스킬인지' 설명이 들어 있어서, 클로드가 대화 내용을 보고 **필요하면 알아서** 가져다 씁니다."
**[자막]** `직접 부르기: / · 자동: 클로드가 필요할 때`
**[말]**
"참고로 작업 중에 명령을 보내도 일반 메시지처럼 전달됩니다."

> 근거: 데스크탑 문서 "Use skills", skills 문서 "How skills are invoked"(자동 로드, `/이름`으로 직접 호출).
> 촬영 주의: 목록에 뜨는 항목은 사용자마다 다릅니다. **실제 목록 화면을 보고** 시연할 항목을 정하세요.

## ⑤ 내 스킬 만들기 ⭐ (4:45 ~ 7:15)

**[자막]** `반복하는 부탁 = 스킬 후보`
**[말]**
"이번엔 내 스킬을 만들어 봅니다. 먼저 스킬이 **어떤 모양의 파일**인지만 알면 돼요. 이름은 `SKILL.md`, 맨 위에 두 줄짜리 머리말이 있고, 그 아래에 클로드가 따를 지침을 적습니다."
**[화면]** 아래 예시를 화면에 크게 띄운다. (**부업 계산기용 예시**, 부록 B-2 템플릿과 동일)

```
---
description: 부업 수익 계산기 결과를 3줄로 요약하고 주의할 점을 알려 준다. 사용자가 순이익 결과를 요약해 달라고 하거나 수입·비용 숫자를 검토해 달라고 할 때 쓴다.
---

## 지침
1. 사용자가 준 수입과 비용을 표로 정리한다.
2. 순이익을 한 줄로 알려 준다.
3. 빠진 비용 항목이 있을 것 같으면 질문 2개를 한다.
4. 쉬운 한국어로, 어려운 용어는 풀어서 쓴다.
```

**[말]**
"머리말의 `description`, 즉 설명이 중요해요. 공식 문서에서도 이 설명 한 줄만큼은 적으라고 권합니다. 클로드가 **언제 이 스킬을 쓸지** 이 설명을 보고 판단하거든요."
**[자막]** `SKILL.md = 머리말(설명) + 지침`
**[말]**
"스킬 이름은 따로 안 적으면 **폴더 이름**이 됩니다. 폴더 이름을 `profit-summary`로 하면 `/profit-summary`로 부를 수 있어요."

**[화면]** 〈분기 A 또는 B 중 촬영에서 실제로 되는 쪽만 남기고 다른 쪽은 삭제〉

> **[말]** "클로드에게 만들어 달라고 해 봤더니 이렇게 파일을 제안합니다. 1편에서 배운 대로 **어디에 무엇을 만드는지 읽고** 허락하세요."
>

**[화면]** 새 세션을 열고 `/` 입력 → 방금 만든 스킬이 목록에 보이는지 확인 → 선택 후 `수입 300만 원, 비용 180만 원이야` 입력.

### C-2. 문서에서 확인하지 못한 것 → 촬영 화면으로 확인

- **데스크탑 앱에서 스킬을 만드는 방법**: 읽은 skills 문서는 파일(`SKILL.md`)을 직접 만드는 방식을 설명합니다. **"클로드에게 스킬을 만들어 달라고 요청"하는 방식이 문서에 있는지는 확인하지 못했고**(문서 요약 중 상반된 결과가 나옴), 데스크탑 앱의 스킬 생성 전용 메뉴도 확인하지 못했습니다. 챕터 ⑤의 분기 A/B를 촬영 때 직접 시험해 결정하세요.
- **Customize 화면에서 스킬을 켜고 끄는 정확한 버튼·화면**, 직접 만든 스킬을 계정에 올리는 방법
- **커넥터 목록의 실제 구성**(문서는 "Google Calendar, Slack, GitHub, Linear, Notion 등"까지만), 서비스별 인증 화면과 권한 문구
- **커넥터 사용 중 나오는 허락 화면**의 모양과 문구
- 앱 **한국어 메뉴 이름**(Customize가 '사용자 지정'이라는 점은 운영자가 확인한 내용이며 문서에는 없음)
- 스킬을 Windows와 macOS에서 실제로 어느 폴더에 저장하는지의 **화면상 표시**
- **요금 금액**: 단정하지 않음. 커넥터·플러그인·스킬이 어떤 요금제에서 되는지도 이 대본에서는 말하지 않았습니다.
