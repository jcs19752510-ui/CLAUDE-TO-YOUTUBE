# 🎁 무료 자료 ③ — AI에게 맡길 일 vs 내가 정할 일 체크리스트

> AI에게 무엇을 맡기고, 무엇은 내가 직접 정해야 하는지 구분하는 점검표입니다.
> 실제 24일 프로젝트에서 **내가 직접 결정했던 지점**과 **사고에서 얻은 교훈**을 바탕으로 만들었습니다.

## 1분 판단법

일을 시키기 전에 이 3가지를 물어보세요.

| 질문 | "예"면 |
|---|---|
| ① **되돌리기 어렵나?** (삭제, 배포, 결제, 외부 공개) | 🔒 **내가 직접 승인** |
| ② **돈·개인정보·법적 책임이 걸려 있나?** | 🔒 **내가 직접 결정** |
| ③ **정답이 없고 취향·방향의 문제인가?** (무엇을 만들까, 어디까지 할까) | 🧭 **내가 정함**, AI는 선택지만 제시 |

세 개 모두 "아니오"라면 → ✅ **AI에게 맡기고 결과만 확인**

---

## A. ✅ AI에게 맡겨도 되는 일

| 일 | 맡길 때 한 줄 | 내가 확인할 것 |
|---|---|---|
| 시험 작성·실행 | "시험은 네가 직접 돌려" | 결과서에 **확인 못 한 것** 항목이 있는지 |
| 반복 작업·정리 | "같은 형식으로 전부 정리해" | 샘플 2~3개만 직접 열어 보기 |
| 문서·결과서 작성 | "무엇을 했고 무엇을 못 했는지 적어" | 안 된 것도 적었는지 |
| 오류 원인 찾기 | "에러 문구를 확인한 뒤에만 원인을 말해" | 추측이 아닌 근거가 있는지 |
| 버그 고치기 | "**먼저 재현 시험부터** 써" | 옛 코드 실패 → 새 코드 통과 |
| 코드 점검(린트·형식) | "완료 전 체크를 전부 통과시켜" | 통과 로그 |
| 의존성 취약점 점검 | "취약점 검사 돌리고 고쳐" | 고친 버전·영향 범위 |

## B. 🔒 내가 직접 승인해야 하는 일

| 일 | 이유 | 규칙 문구 예시 |
|---|---|---|
| 실제 서비스 배포 | 되돌리기 어렵고 사용자에게 영향 | "배포는 내 명시적 승인 후에만" |
| 데이터 삭제·덮어쓰기 | 복구 불가 | "삭제 전에 대상을 먼저 보여줘" |
| 유료 서비스 가입·결제 | 돈이 나감 | "비용이 드는 작업은 먼저 묻는다" |
| 비밀번호·API 키 다루기 | 유출 위험 | "비밀값은 출력·기록 금지" |
| 외부로 데이터 전송 | 한 번 나가면 못 거둠 | "외부 전송 전 내용을 보여준다" |
| 공개 범위 변경 | 노출 위험 | "공개 설정은 내가 직접" |

## C. 🧭 내가 정해야 하는 일 (방향·취향·책임)

실제 프로젝트에서 **사람이 직접 정했던 것들**입니다.

| 결정 | 실제 사례 | 왜 사람이 정해야 하나 |
|---|---|---|
| 데이터 출처·비용 | 상용 시세 서비스 대신 증권사 API 사용 | 비용·계약·개인용 여부는 내 상황 |
| 화면 문구의 법적 선 | "투자 권유 표현" 자동 차단 도구 도입 | 법적·윤리적 책임은 내 몫 |
| 배포 방식 | 무료 서버에 올렸다가 개인 노트북으로 되돌림 | 쓰임새와 위험을 내가 판단 |
| 사용자 정책 | 비밀번호 최소 길이를 12자 → 8자로 변경 | 편의와 안전의 균형은 내가 결정 |
| 우선순위 | "실시간으로 정확하게 보이는가"를 최상위 기준으로 고정 | 프로젝트의 목적은 내가 정함 |

## D. ⚠ AI가 놓치기 쉬운 것 — 사고 예방 점검

실제 사고(대체공휴일로 데이터가 멈춘 일)에서 얻은 교훈입니다.

- [ ] **휴일·주말·마감일·시간대**를 다루는 기능인가? → "휴일에도 테스트했어?"
- [ ] **외부 데이터가 늦게 올 수 있나?** → "아직 안 나온 것"과 "실패한 것"을 구분하는가?
- [ ] **실패 횟수 상한**이 있나? → 일시적 실패가 영구 포기로 이어지지 않는가?
- [ ] **중간에 빈 날(구멍)**이 있으면 조용히 틀린 값을 내지 않고 **멈춰서 경고**하는가?
- [ ] 고쳤다고 할 때 **같은 사고를 재현하는 시험**이 있는가?
- [ ] 화면에 "지금 보는 데이터가 언제 기준인지" **지연·불일치를 표시**하는가?

## E. 일 시키기 전 / 후 점검표 (인쇄해서 쓰세요)

**시키기 전**
- [ ] 이 일은 되돌릴 수 있는가?
- [ ] 돈·개인정보·법적 책임이 걸려 있는가?
- [ ] 규칙 파일(자료 ①)에 필요한 규칙이 있는가?
- [ ] 어디까지 해도 되는지 범위를 말해 줬는가?

**끝난 뒤**
- [ ] 결과서에 **확인하지 못한 것**이 적혀 있는가?
- [ ] 시험을 AI가 직접 돌렸는가(나에게 시키지 않았는가)?
- [ ] 샘플을 내가 직접 열어서 확인했는가?
- [ ] 비밀값이 화면·코드·로그에 노출되지 않았는가?
- [ ] 결정한 내용과 이유가 기록되었는가?

## F. 한 줄 요약

> **AI는 "실행"을 맡고, 나는 "결정"을 쥔다.**
> 되돌릴 수 없는 일과 책임이 걸린 일은 내가, 반복과 확인은 AI가.
