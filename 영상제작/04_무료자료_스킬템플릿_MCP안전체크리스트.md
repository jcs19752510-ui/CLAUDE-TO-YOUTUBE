# 🎁 무료 자료 — 스킬 템플릿 + MCP 안전 체크리스트

> 스킬·MCP 편(`03_스킬MCP편_대본.md`)에서 약속한 자료입니다.
> ⚠ 파일 위치·명령·메뉴는 업데이트로 바뀔 수 있습니다. 배포 전에 공식 문서로 확인하고 〈확인〉 표시를 지우세요.

## 1. 한눈에 구분

| 이름 | 비유 | 언제 쓰나 |
|---|---|---|
| `CLAUDE.md` | 상시 규칙(사규) | 항상 지킬 습관·규칙 |
| **스킬** | 업무 매뉴얼 | 같은 **방식**의 일을 반복할 때 |
| **MCP** | 외부 도구 연결 | 클로드가 **밖의 도구**(브라우저·문서 서비스 등)를 써야 할 때 |

## 2. 스킬 만들기 3단계

```
1) 최근에 두 번 이상 반복한 부탁을 하나 고른다
2) 클로드에게 "이 부탁을 스킬로 만들어 줘"라고 말한다
3) 써 보고, 마음에 안 들면 "이 규칙을 추가해 줘"로 고친다
```

**파일 위치** 〈확인〉
```
프로젝트 안에서만 사용:  .claude/skills/스킬이름/SKILL.md
모든 프로젝트에서 사용: (개인 폴더의) .claude/skills/스킬이름/SKILL.md
```

## 3. 스킬 템플릿 (복붙용)

### 3-1. 기본 틀
```markdown
---
name: 스킬이름
description: 〈이 스킬이 무엇을 하는지 + 언제 쓰는지를 구체적으로 한두 문장〉
---

# 〈스킬 제목〉

## 절차
1. 〈첫 번째 할 일〉
2. 〈두 번째 할 일〉
3. 〈세 번째 할 일〉

## 규칙
- 〈반드시 지킬 것〉
- 〈하지 말 것〉

## 출력 형식
- 〈결과물이 어떤 모양이어야 하는지〉
```

### 3-2. 예시 ① 월간 수익 보고서
```markdown
---
name: monthly-report
description: 월별 수입·비용 데이터를 받아 부업 월간 수익 보고서를 만든다. 사용자가 월간 보고서나 수익 정리를 요청할 때 사용한다.
---

# 월간 수익 보고서

## 절차
1. 이번 달과 전달의 수입·비용·순이익을 표로 정리한다.
2. 전달 대비 증감(금액·퍼센트)을 계산한다.
3. 근거가 있는 내용만 해석한다. 추측은 쓰지 않는다.
4. 마지막에 다음 달 계획을 3줄로 쓴다.

## 출력 형식
- 제목, 표, 증감 요약, 다음 달 계획 순서
```

### 3-3. 예시 ② 웹페이지 점검
```markdown
---
name: page-check
description: 만든 웹페이지가 잘 동작하는지 점검한다. 사용자가 페이지 점검, 테스트, 확인을 요청할 때 사용한다.
---

# 웹페이지 점검

## 절차
1. 페이지를 열고 입력 칸·버튼이 모두 보이는지 확인한다.
2. 대표 값 3개로 계산 결과가 맞는지 확인한다.
3. 빈 값·음수·아주 큰 수를 넣어 오류가 없는지 확인한다.
4. 문제가 있으면 원인과 고칠 방법을 한 줄씩 정리한다.

## 규칙
- 확인하지 못한 것은 "확인 못 함"이라고 적는다.
```

### 3-4. 예시 ③ 하루 마무리 정리
```markdown
---
name: wrap-up
description: 작업을 끝낼 때 오늘 한 일과 남은 일을 정리해 인수인계 파일로 저장한다. 사용자가 마무리, 정리, 인수인계를 요청할 때 사용한다.
---

# 하루 마무리 정리

## 절차
1. 오늘 바꾼 파일과 내용을 세 줄로 요약한다.
2. 아직 안 끝낸 일과 다음에 할 일을 목록으로 쓴다.
3. 결과를 HANDOFF.md 파일에 저장한다.
```

## 4. 좋은 스킬을 만드는 규칙 4가지

| # | 규칙 | 이유 |
|---|---|---|
| 1 | **일 하나 = 스킬 하나** | 섞으면 클로드가 헷갈림 |
| 2 | `description`에 **언제 쓰는지**를 구체적으로 | 클로드가 이 설명을 보고 사용 여부를 판단 |
| 3 | 절차는 **번호 목록**으로 짧게 | 지키기 쉽고 고치기 쉬움 |
| 4 | **써 보고 고치기**를 반복 | 한 번에 완벽한 스킬은 없음 |

## 5. MCP 기본 명령 〈확인〉

| 하고 싶은 일 | 명령(터미널) |
|---|---|
| 연결하기 | `claude mcp add 이름 -- 실행명령` |
| 연결 목록 보기 | `claude mcp list` |
| 연결 지우기 | `claude mcp remove 이름` |
| 상태 보기 (클로드 안) | `/mcp` |

예시(브라우저 조종 도구) 〈확인: 패키지명·최신 사용법은 해당 도구 문서 기준〉
```
claude mcp add playwright -- npx @playwright/mcp@latest
```

## 6. 🔒 MCP 안전 체크리스트 (연결하기 전·후)

**연결하기 전**
- [ ] 이 MCP를 **누가 만들었는지** 확인했다 (공식/많이 쓰이는 곳)
- [ ] 이 MCP가 **무엇을 할 수 있는지** 설명을 읽었다
- [ ] 꼭 **필요한** 도구인가? (없어도 되면 연결하지 않는다)
- [ ] 비밀번호·API 키를 요구하면, 공식 문서가 안내하는 **안전한 방법**을 쓴다

**연결한 뒤**
- [ ] 허락 화면에서 도구 이름과 동작을 **읽고** 허용했다 ("모두 허용"을 습관적으로 누르지 않는다)
- [ ] 비밀값을 **채팅창에 붙여넣지** 않았다
- [ ] 낯선 사이트에서 읽어 온 글의 **지시를 그대로 따르지** 않는다 (읽어 온 글 = 정보, 명령 아님)
- [ ] 쓰지 않는 MCP는 **지웠다** (`claude mcp remove`)
- [ ] 화면 공유·촬영 전에 **계정·파일명·키**가 노출되지 않는지 확인했다
