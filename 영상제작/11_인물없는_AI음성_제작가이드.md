## 3. 음성 만들기 (`조립/make_voice.py`)

### 3-1. 입력과 출력
| 구분 | 내용 |
|---|---|
| 입력 | `10_AI음성_입력용_대본.md` (영어·기호를 발음대로 바꾼 낭독 대본. **줄바꿈 한 번 = 한 문단**, 챕터 ①~⑩이 먼저 나오고 ⑪~⑳은 파일 뒤쪽(첫 `---` 아래)에 모여 있음 — **파일 안 순서 ≠ 영상 재생 순서**) |
| 출력 | `음성/V{챕터 2자리}_p{문단 2자리}.mp3` (예: `V07_p06.mp3` = ⑦ 챕터의 7번째 문단, `V20_p09.mp3` = ⑳ 챕터의 마지막 문단) |
| 보관 | `음성/_원본/chapter_01.mp3 …` : 문단 분리 전 **챕터 전체 원본**(재분리용). ⚠ ①②⑩의 원본은 이전 구성 글로 만든 것이라 **다시 분리하면 옛 음성이 되살아납니다** |
| 문단 수 | 챕터별: ① 2 · ② 4 · ③ 8 · ④ 5 · ⑤ 2 · ⑥ 3 · ⑦ 10 · ⑧ 9 · ⑨ 5 · ⑩ 2 · ⑪ 1 · ⑫ 5 · ⑬ 3 · ⑭ 5 · ⑮ 4 · ⑯ 2 · ⑰ 3 · ⑱ 6 · ⑲ 7 · ⑳ 10 = **총 96개** |

### 3-2. 재사용 42 / 재생성 54 — 무엇을 다시 만드나

| 구분 | 문단 수 | 내용 |
|---|---|---|
| **재사용** (기존 음성 그대로) | **42** | ① p00 / ② p00·p01·p03 / ③ 전부(8) / ④ 전부(5) / ⑤ 전부(2) / ⑥ 전부(3) / ⑦ 전부(10) / ⑧ 전부(9) / ⑩ p00. **글이 이전과 같으니 다시 만들지 마세요.** |
| **수정해서 다시 만들기** | **3** | `V01_p01`(30분·치트시트와 안전 체크리스트), `V02_p02`(오늘 순서 5가지 + "목소리는 AI 음성"), `V10_p01`(오늘 쓴 프롬프트·예약 작업 예고). 파일 이름은 그대로 |

| **재생성 합계** | **54** | 3 + 51 |

> 단, ④의 "탭이 세 개 있습니다"는 **내 화면이 세 탭일 때만** 맞습니다(메인 대본 부록 C-2). 내 앱이 챗·코워크 합쳐진 화면이면 ④의 해당 문단만 고쳐 다시 만들면 됩니다.

### 3-3. 실행 방법 — 요청 14회 방식

**결제가 연결된 Gemini API 키가 필요합니다.** 54문단을 새로 만들고 다시 시도할 수 있어 무료 한도로는 부족할 수 있습니다(무료 한도의 정확한 숫자는 확인하지 못했습니다 → 아래 3-4, 확인 필요). **키는 채팅·파일에 적지 마세요.** 결제가 연결된 키가 새어 나가면 요금이 나갈 수 있습니다. 두 가지 중 하나로 전달합니다.
1. 클라우드 세션: 환경에 등록한 **네트워크 시크릿**이 요청에 자동으로 붙습니다.
2. 내 PC: 환경 변수 `GEMINI_API_KEY`에 키를 넣고 실행합니다.

**먼저 확인**: `조립/make_voice.py`와 `조립/common.py`가 **⑪~⑳을 읽도록 고쳐졌는지**(챕터 목록 20개, 문단 파서 범위, `--only 1~20`). 고쳐지기 전에 돌리면 ①~⑩에는 영향이 없지만 ⑪~⑳은 만들어지지 않습니다(`조립/음성_재생성_목록.md` 5장) — 확인 필요.

**1단계 — 수정 문단 3개 (문단 모드, 요청 3회)**
```
(직접) 음성/V01_p01.mp3, 음성/V02_p02.mp3, 음성/V10_p01.mp3 를 지운다
python 조립/make_voice.py --mode paragraph --only 1
python 조립/make_voice.py --mode paragraph --only 2
python 조립/make_voice.py --mode paragraph --only 10
```
- **반드시 `--mode paragraph`** 를 붙이세요. 기본인 챕터 모드로 돌리면 보관된 **옛 원본**을 다시 분리해 옛 문장의 음성이 되살아납니다.
- 문단 모드는 **이미 있는 파일은 건너뛰고** 없는 파일만 만듭니다. `--overwrite`(챕터 전체를 다시 만듦)와 `--resplit`(옛 원본으로 덮어씀)은 ①②⑩에 **쓰지 마세요.**

**2단계 — 새 챕터 11개 (챕터 모드, 요청 11회)**: ⑨, ⑪~⑳을 챕터마다 1회씩
```
python 조립/make_voice.py --only 9
python 조립/make_voice.py --only 11
… (12~20 반복)
```

| 방식 | 요청 수 |
|---|---|
| **권장: 1단계 3회 + 2단계 11회** | **14회** |
| 전부 챕터 모드로 새로 만들기 (재사용 42개 폐기) | 20회 |
| 전부 문단 모드로 새로 만들기 | 96회 |

| 옵션 | 기본값 | 뜻 |
|---|---|---|
| `--model` | `gemini-3.8-flash-lite-tts` (스크립트 기본값) | 사용할 음성 모델. 모델마다 하루 무료 한도가 따로 있음(3-4). 모델 이름은 Google 문서에서 **확인 필요** |
| `--voice` | `Kore` | 목소리 이름 |
| `--speed` | `0.92` | 말 속도 배율(1.0 = 원래, 낮을수록 느림). **파일 후처리**로 조절(프롬프트에 속도 지시를 넣으면 지시문이 음성으로 읽힐 수 있어 쓰지 않음). 새 문단과 재사용 문단의 속도가 같아야 합니다 |
| `--mode` | `chapter` | `chapter`: **챕터마다 1회 요청**(기본, 하루 한도 절약) / `paragraph`: 문단마다 요청 |
| `--only N` | 전체 | N번 챕터(스크립트 갱신 후 1~20)만 생성 |
| `--gap` | `12` (초) | 요청 사이 대기. 한도 보호용 |
| `--overwrite` | 꺼짐 | API를 **다시 호출**해 새로 만듦 (한도를 씀). 재사용 음성을 지울 수 있으니 주의 |
| `--resplit` | 꺼짐 | 보관된 원본 챕터 음성으로 **문단만 다시 분리**(API 호출 없음) |
| `--script` | `10_AI음성_입력용_대본.md` | 입력 대본 경로 |
| `--out` | `음성/` | 출력 폴더 |

**챕터 모드 동작**: 한 챕터의 문단들을 **빈 줄로 이어 한 번에 요청** → 원본을 `음성/_원본/chapter_NN.mp3`에 보관 → 문단 사이 **쉬는 구간(무음)** 을 찾아 문단 수만큼 분리 → 앞뒤 무음을 다듬고 속도를 조절해 `V??_p??.mp3`로 저장합니다. 분리가 실패하면 경고하고 챕터 전체 파일만 저장합니다. 글자 수 대비 길이가 이상한 문단(초당 3.5자 미만 또는 9자 초과)은 `⚠ 길이 이상(잘림·누락 의심)`으로 표시하니 **그 파일은 직접 들어 보세요.** ⑳(10문단, 1,186자)처럼 긴 챕터는 문단 분리가 어긋나기 쉬우니 특히 확인하세요.

### 3-4. Gemini 한도 (현재 확인된 사실)

| 한도 | 내용 | 대처 |
|---|---|---|
| **분당 한도** | 짧은 시간에 요청이 몰리면 HTTP **429**가 뜸 | **대기 후 재시도로 풀림.** 스크립트가 20초 × 시도 횟수만큼 기다리며 자동 재시도(최대 6회) |
| **하루 한도** | **모델마다 하루 요청 수 한도가 따로** 있음(무료 구간의 한도 이름: `GenerateRequestsPerDayPerProjectPerModel-FreeTier`) | 재시도로 **풀리지 않음.** 무료 구간은 약 **15시간 뒤 초기화**. 그전에는 다른 모델(`--model`)을 쓰거나, 다른 프로젝트의 키를 쓰거나, **결제가 연결된 키**로 전환 |
| 중단 시 | 스크립트가 "[중단] 하루 무료 한도를 모두 썼습니다"로 멈춤 | **이미 만든 파일은 건너뛰고 이어서 만듭니다.** 한도가 풀린 뒤 같은 명령을 다시 실행 |

- **요청 수 줄이기**: 문단마다 요청하면 96회, **챕터마다 1회 요청이면 새 챕터 11회**입니다. 그래서 새 챕터는 챕터 모드, 수정 3문단만 문단 모드를 씁니다(합계 14회).
- 하루 요청 수의 **정확한 숫자와 모델별 한도, 결제 연결 시 요금**은 제가 확인하지 못했습니다. Google의 한도 안내 페이지와 내 프로젝트의 사용량 화면에서 **확인 필요**.
- 한도·요금을 아끼려면: 처음에는 `--only N`으로 챕터 하나만 테스트하고, 발음 수정 후에는 **`--overwrite`가 해당 챕터의 요청을 다시 씁니다**(챕터당 1회). 속도만 바꾸는 경우는 API 없이 `--resplit --speed 0.9`처럼 **원본에서 다시 분리**하세요(단, ①②⑩에는 쓰지 말 것).
