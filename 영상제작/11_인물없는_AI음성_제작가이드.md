# 인물 없는 AI 음성 버전 — 제작 가이드 (방법 3)

> **결정 사항**: ① 얼굴(인물) 없이 만든다 ② 목소리는 **AI 음성으로 시작**하고, 듣고 나서 어색하면 **본인 녹음으로 교체**한다(파일 구조가 같아 언제든 교체 가능) ③ 화면 시연은 **직접 녹화한 실제 화면**을 쓴다.
> 이 문서는 기존 `05_제작_가이드_초보용.md`를 **대체하는 부분만** 다룹니다. 나머지(OBS 설정, 편집 프로그램 사용법, 업로드 설정)는 05번 문서를 그대로 따르세요.

## 0. 왜 이렇게 정했나

| 선택 | 이유 |
|---|---|
| 인물 없음 | AI 아바타가 "제가 직접 해 봤어요"라고 말하면 거짓이 됩니다. 인물 없는 영상은 **화면 시연이 주인공**이라 정직하고 쉽습니다. |
| AI 음성으로 시작 | 녹음 장비·방·NG 부담이 없고 빠릅니다. 초안은 AI 음성으로 만들어 보고 반응을 본 뒤 결정합니다. |
| 본인 녹음 교체 가능 | 채널의 강점은 실제 개발자의 경험입니다. 시청자 반응에 따라 목소리를 바꿀 수 있어야 합니다. |

> **한계**: 이 환경에서는 AI 음성을 직접 만들 수 없어, 음성 생성은 **사용자가 외부 서비스에서** 합니다. 제가 만든 것은 음성 입력용 대본·시각 자료·편집 가이드입니다.

## 1. 전체 흐름 (인물 없는 버전)

```
[1] 목소리 고르기(1분 테스트) → [2] 음성 만들기(챕터별 V01~V10) → [3] 화면 녹화(B1~B11, 무음)
  → [4] 편집: 음성 깔기 → 화면·그래픽 얹기 → 자막 → [5] 내보내기 → [6] 업로드(AI 음성 고지)
  → [7] 점검 → [8] 목소리 방식 결정(AI 유지 / 본인 전환)
```

**기존 가이드에서 달라지는 점**

| 기존 | 이 버전 |
|---|---|
| 얼굴 촬영 A1~A10 | **삭제** (찍지 않음) |
| 말소리는 촬영 때 같이 | **음성 파일 V01~V10**을 따로 만듦 |
| 얼굴이 나오던 구간 | 챕터 카드, 도식 영상, 화면 녹화, 강조 자막으로 대체 |
| 편집: 얼굴 영상이 기준 줄기 | 편집: **음성 파일이 기준 줄기** |

## 2. 목소리 고르기 (1분 테스트, 처음에만)

1. 사용할 AI 음성 서비스를 2~3개 고릅니다. ⚠ 서비스 이름·요금·한국어 품질·**상업 이용(유튜브 수익 창출 포함) 약관**은 제가 확인하지 못했으니 직접 확인하세요. 예: 브루(Vrew)의 AI 목소리, 타입캐스트, 네이버 클로바 더빙 등.
2. 같은 문단(`10_AI음성_입력용_대본.md`의 ⑥ 첫 문단)을 각 서비스에 넣어 **같은 길이**로 만듭니다.
3. 아래 표로 점수(1~5)를 매깁니다.

| 항목 | 서비스 A | 서비스 B | 서비스 C |
|---|---|---|---|
| 발음이 자연스러운가 | | | |
| 속도·쉼이 편한가 | | | |
| 영어 단어(클로드 엠디 등) 발음 | | | |
| 10분 들어도 피곤하지 않은가 | | | |
| 상업 이용 약관 확인 | ✔/✘ | ✔/✘ | ✔/✘ |

4. **합계가 높고 약관이 ✔인 것**을 고르세요. 약관이 ✘이면 점수와 무관하게 쓰지 마세요.

> **본인 목소리로 전환하고 싶다면**: 마이크만 있으면 됩니다(얼굴 불필요). `07_읽기용_대본.md`를 읽어 챕터별로 녹음하고, 같은 파일명(`V01_…`)으로 저장하면 나머지 과정은 동일합니다.

## 3. 음성 만들기 (챕터별 10개 파일)

### 3-1. 입력 대본
`10_AI음성_입력용_대본.md`를 사용합니다. 영어·기호가 이미 발음대로 바뀌어 있습니다(예: `CLAUDE.md` → 클로드 엠디, `Esc` → 이에스씨).

### 3-2. 예시: ⑥ 챕터 만들기
1. 서비스에 새 프로젝트를 만들고 목소리를 선택합니다.
2. **속도는 기본값 또는 약간 느리게**(왕초보 대상이라 빠르면 못 따라옵니다).
3. ⑥ 챕터의 문단을 붙여넣고 **문단 사이에 0.5~1초 쉼**을 넣습니다.
4. 생성 → 이어폰으로 **처음부터 끝까지 들어 봅니다.**
5. 어색한 단어는 **한글 발음 그대로** 고쳐 다시 생성합니다.

| 들어 보니 | 고치기 |
|---|---|
| "클로드 엠디"가 어색 | "클로드 엠 디" 또는 "클로드 마크다운 파일" |
| "슬래시 이닛" 발음이 이상 | "슬래시 이니트" |
| 숫자 "3가지"를 "삼 가지"로 읽음 | "세 가지" |
| 문장이 너무 빨리 이어짐 | 문장 끝에 쉼표·마침표 추가 |

6. 만족하면 파일 이름을 규칙대로 저장합니다.

| 챕터 | 파일 이름 | 예상 길이(대략) |
|---|---|---|
| ① 하이라이트 | `V01_하이라이트.mp3` | 약 35초 |
| ② 통증+약속 | `V02_통증약속지도.mp3` | 약 65초 |
| ③ 선택표 | `V03_선택표.mp3` | 약 95초 |
| ④ 설치·로그인 | `V04_설치로그인.mp3` | 약 60초 |
| ⑤ 첫 프로젝트 | `V05_첫프로젝트.mp3` | 약 75초 |
| ⑥ CLAUDE.md | `V06_CLAUDEMD.mp3` | 약 60초 |
| ⑦ 플랜 모드 | `V07_플랜모드.mp3` | 약 75초 |
| ⑧ 안전장치 | `V08_안전장치실수.mp3` | 약 30초 |
| ⑨ 비용·기억 | `V09_비용기억클릭.mp3` | 약 25초 |
| ⑩ 마무리 | `V10_맛보기요약.mp3` | 약 60초 |

> 길이는 글자 수로 계산한 어림값(1초 약 4.8자)이며, 서비스와 속도에 따라 달라집니다. **실제 파일의 길이**로 편집하세요. 합계는 약 9~10분입니다.

## 4. 대본에서 고칠 부분 (인물이 없어서)

| 위치 | 기존 | 고친 문장 / 처리 |
|---|---|---|
| ② 화면 | "얼굴, 큰 자막" | **키워드 카드**(챕터 카드 + 강조 자막)로 대체 |
| ② 인사 | "안녕하세요, 〈본인 소개 한 줄〉입니다." | "안녕하세요, 〈채널 이름〉입니다. 이 영상은 AI 음성으로 안내합니다." |
| ② 자막 | "〈본인 소개 자막〉" | 채널 이름 자막 + AI 음성 고지 카드(12번) |
| ① 시작 | "이 웹페이지, 코드를 한 줄도 직접 안 쓰고…" | **실제로 그랬을 때만** 유지. 아니면 사실대로 수정 |
| 전체 | "제가 …" (1인칭) | 채널 운영자가 실제로 한 행동일 때만 유지. 의심되면 "이 영상에서는 …해 봅니다"로 변경 |

> **AI 음성 고지는 영상 초반과 설명란 양쪽에** 넣으세요. 시청자가 AI 음성임을 알 수 있어야 합니다.

## 5. 새 시각 구성 (인물 없는 편집 지도)

> 기준: 음성 파일이 줄기. 각 챕터 시작에는 **챕터 카드**(3초)를 넣어 구분합니다. 파일은 `그래픽/영상_mp4/챕터카드/`에 있습니다.

| 챕터 | 시각 소스 (순서대로) |
|---|---|
| ① | 챕터 카드 생략 가능 → `B1` 계산기 시연 → `B2` 에러 화면 → `01_타이틀카드` |
| ② | 챕터 카드 `11_챕터02` → **AI 음성 고지 카드 `12`** → 강조 자막 → `02_오늘배울3가지` |
| ③ | `11_챕터03` → `B3`(챗·코워크·코드 메뉴 화면 순서대로) → `03_챗코워크코드_선택표` |
| ④ | `11_챕터04` → `04_설치3단계` → `B4` 설치 화면 → `05_로그인_폴더신뢰` → `B5` |
| ⑤ | `11_챕터05` → `B6` 첫 프로젝트(대기 시간은 빠르게) → `B7` |
| ⑥ | `11_챕터06` → 강조 자막 "CLAUDE.md = 업무 지침서" → `B8` |
| ⑦ | `11_챕터07` → `B9` 플랜 모드 |
| ⑧ | `11_챕터08` → `06_안전장치_키3개` → `B10` → `07_초보실수3가지` |
| ⑨ | `11_챕터09` → `08_비용기억클릭관리` → `B11` |
| ⑩ | `11_챕터10` → `09_5줄요약` → `10_엔드카드_20초` |

> **카드는 필요한 곳에만** 쓰세요. 챕터마다 3초씩이면 30초이고, 너무 많으면 템포가 끊깁니다. 흐름이 자연스러운 곳은 카드를 생략해도 됩니다.

### 5-1. 가장 중요한 요령: 음성 길이에 화면을 맞추기

화면 녹화는 시간이 제각각이라 음성과 안 맞습니다. 이렇게 맞춥니다.

| 상황 | 해결 |
|---|---|
| 화면이 음성보다 **길다** | 클립 속도를 **빠르게**(2~4배속), 대기 시간을 자르기 |
| 화면이 음성보다 **짧다** | 마지막 프레임을 **정지**시켜 늘리거나, 확대(줌인)로 강조, 도식 카드를 이어 붙이기 |
| 중요한 화면이 놓침 | 음성을 **한 문단 단위로 자르고**(쉼 구간) 그 사이에 화면을 정렬 |

## 6. 편집 순서 (기존 05번 가이드의 5단계를 이렇게 바꿈)

1. **음성 파일 10개를 시간순으로 타임라인에 올린다**(문단 사이 쉼 포함). 이것이 줄기입니다.
2. 각 챕터의 **화면 녹화(B)** 를 음성 위 트랙에 올린다.
3. **도식·카드 영상**을 5장의 표대로 올린다.
4. **강조 자막**(`자막/강조자막_초안.srt`)을 넣고 시간을 조정한다. 도식 영상과 겹치는 문구는 지운다.
5. **대사 자막**: 음성이 있으므로 편집 프로그램의 **자동 자막**(Vrew, CapCut)으로 생성한 뒤 틀린 글자를 고친다.
6. **배경음**: 말소리보다 훨씬 작게. 쓰지 않아도 됩니다. 저작권 안전한 음원만.
7. **소리 점검**: 챕터별 음량 차이가 없는지, 문단 사이 쉼이 어색하지 않은지.
8. 내보내기(1080p / 30fps / MP4).

### 예시: 영상 처음 40초 (인물 없는 버전)

| 시간 | 화면 | 음성 | 자막 |
|---|---|---|---|
| 0:00~0:08 | `B1` 계산기 시연 | V01 첫 문장 | – |
| 0:08~0:15 | `B2` 에러 화면 | V01 둘째 문장 | "처음엔 이렇게 망했습니다" |
| 0:15~0:22 | 치트시트 이미지 | V01 셋째 문장 | "무료 치트시트" |
| 0:22~0:26 | `01_타이틀카드` | – | – |
| 0:26~0:30 | `12_AI음성고지카드` | – | – |
| 0:30~0:55 | 키워드 카드 + 강조 자막 | V02 첫 문단 | 대사 자막 |

## 7. 업로드 때 달라지는 점

1. **설명란에 AI 음성 고지**를 넣으세요.
```
※ 이 영상의 목소리는 AI 음성입니다. 화면 시연은 직접 녹화한 실제 화면입니다.
```
2. 업로드 설정의 **변경된 콘텐츠(합성·AI) 질문**에는 문구를 읽고 정직하게 답하세요. ⚠ AI 음성이 실제 사람처럼 들리는 경우 표시 대상이 될 수 있으니 스튜디오 안내와 공식 도움말에서 기준을 확인하세요.
3. 같은 형식의 AI 음성 영상을 **대량으로** 올리면 "반복적이거나 진정성 없는 콘텐츠"로 수익 창출이 제한될 수 있습니다. ⚠ 정확한 기준은 공식 정책에서 확인하세요. 영상마다 **직접 만든 시연과 설명**이 들어가면 유리합니다.
4. 나머지(제목, 설명, 썸네일, 최종 화면)는 05번 가이드 6단계와 동일합니다.

## 8. 점검 + 목소리 방식 결정

**24시간·72시간 점검**은 05번 가이드와 같습니다. 여기에 목소리 판단 항목을 더합니다.

| 신호 | 해석 | 조치 |
|---|---|---|
| 댓글에 "목소리가 어색해요" | 음성 품질 문제 | 음성 서비스·속도 조정, 또는 본인 녹음 전환 |
| 시청 지속률이 초반(0~30초)에 급락 | 목소리·첫 장면 문제 가능 | 첫 문단만 본인 녹음으로 교체해 A/B 비교 |
| 지속률이 완만하고 댓글이 내용 중심 | 문제 없음 | AI 음성 유지 |

> **다음 편 전략**: 1편은 AI 음성, 2편(스킬·MCP 편) 첫 1분을 본인 녹음으로 바꿔 반응을 비교해 보세요. 데이터가 방식을 알려 줍니다.
