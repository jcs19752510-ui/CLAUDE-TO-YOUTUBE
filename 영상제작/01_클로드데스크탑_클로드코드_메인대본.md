### C-2. 문서에서 확인하지 못한 것 → 촬영 때 화면으로 확인 (대사에는 단정하지 않음)

- **코워크로 들어가는 방식이 문서마다 다릅니다.** 데스크탑 문서는 "Chat · Cowork · Code 세 탭", 도움말은 "메시지 상자에서 Cowork 선택", 최근 도움말은 "챗과 코워크가 한 화면으로 합쳐지는 중(계정마다 시기가 다름)"입니다. 15분본 ④의 "탭이 세 개 있습니다"는 **본인 화면이 세 탭일 때만 맞습니다.** 합쳐진 화면이면 ④·⑥·⑲ 화면 자막을 맞추세요(⑲은 대사가 이미 세 경우를 모두 포함). ④의 음성 문단은 그대로 두었으므로, 화면이 다르면 해당 음성 문단만 다시 만들어야 합니다.
- **Chat 탭의 세부 기능**(파일 첨부 가능 여부 등): 대본은 "파일 접근 없는 일반 대화"만 말합니다.

|---|---|
| 새 챕터 번호를 ⑪~⑳으로 붙이고 ①~⑩ 번호는 그대로 | 기존 음성 파일(`V01_p00` 등)을 이름 그대로 다시 쓰기 위해. 재생 순서는 번호 순서와 다름(⑪은 ⑦ 안, ⑩이 맨 끝) |

| 이론(⑫~⑱) 전부를 끝낸 뒤 실전 2건(⑲⑳)을 마지막에 배치 | 20분 지점에 "설명 끝, 실전 시작" 전환점을 만들어 재참여 장치로 씀. 실전에서 앞에서 배운 내용을 복습하게 됨 |
| 2편의 ① 하이라이트·② 통증+약속·⑩ 요약을 합치지 않음 | 메인 영상의 ①②⑩과 중복되고 시간만 늘어남. 2편의 콜드 오픈(캘린더)은 ⑯으로 대체 |
